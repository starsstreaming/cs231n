# CS231n 中文学习笔记

一些笔记，一些思考。记录学习 Stanford CS231n（计算机视觉深度学习课程）时，对概念、公式、代码和经典论文的理解。

目前收录 **7 份学习笔记**，从图像分类、优化与反向传播，逐步走向 CNN（卷积神经网络）和 Transformer（基于注意力机制的网络）。笔记包含知识梳理、推导示例、代码片段、常见误区和自测题，适合按课程顺序学习，也方便按主题复习。

## 建议学习路线

**视觉与分类基础 → 损失函数与优化 → 神经网络与反向传播 → CNN 与训练方法 → 注意力与 Transformer**

1. **建立地图**：阅读第 1、2 讲，理解图像如何表示、分类器输出什么，以及损失函数如何评价预测。
2. **理解模型如何学习**：阅读第 3、4 讲，串起前向计算、损失、反向求导和参数更新。
3. **学习图像网络**：结合第 5 讲与练习手算卷积尺寸、参数量和梯度，再用第 6 讲理解经典架构与训练方法。
4. **进入注意力模型**：阅读第 8 讲，重点追踪 Q、K、V 的来源、矩阵形状和注意力权重的计算过程。

每篇可以按“学习目标 → 直觉与公式 → 小例子或代码 → 自测题”的顺序阅读。遇到矩阵运算时，先标注每个张量的形状，再检查运算是否成立。

第 8 讲涉及 RNN（循环神经网络）和 Seq2Seq（序列到序列模型）；如果尚不熟悉，可以先从该篇的“从 RNN 到注意力”一节补齐背景。
