## 1. 图像分类任务

### 1.1 任务定义

**图像分类（image classification）**：给定一张输入图像和一个**固定的类别集合**（例如 {dog, cat, truck, plane, …}），为图像分配其中**一个**标签。

它是计算机视觉的核心任务之一。课程笔记指出，很多看似不同的视觉任务（例如**目标检测（object detection）**：找出图中物体的位置和类别；**分割（segmentation）**：为每个像素分配类别）都可以部分归结为分类问题。

**计算机眼中的图像**：一个取值在 $[0, 255]$ 的整数**张量（tensor）**（张量：多维数组）。例如课件中的猫图大小为 $800 \times 600 \times 3$，其中 3 表示 **RGB 三个颜色通道（channel）**（通道：每个像素在红、绿、蓝三种颜色上的强度）。

### 1.2 语义鸿沟与挑战

**语义鸿沟（semantic gap）**：人类看到的是「一只猫」这一**语义概念**，而计算机看到的只是一大堆数字。从数字到语义之间的巨大距离就是语义鸿沟。

> 💡 **要点**：即使「猫」没有变，只要相机稍微移动，**所有像素值都会改变**（课件第 9 页）。这说明不能靠「像素值精确相等」来识别物体。
>

课件与笔记列出的主要挑战：

| 挑战 | 英文 | 含义 |
| --- | --- | --- |
| 视角变化 | Viewpoint variation | 同一物体从不同角度拍摄，像素完全不同 |
| 光照 | Illumination | 光照条件对像素值影响巨大 |
| 背景杂乱 | Background clutter | 物体与背景融为一体，难以区分 |
| 遮挡 | Occlusion | 物体只露出一小部分（甚至只有几个像素） |
| 形变 | Deformation | 非刚体（如猫）可以摆出各种姿势 |
| 类内差异 | Intraclass variation | 同一类别内部外观差别很大（各种品种的猫） |
| 上下文 | Context | 场景上下文可能误导识别（课件第 15 页） |
| 尺度变化 | Scale variation | 物体大小不同（笔记补充） |

一个好的分类模型要对上述所有变化的「组合」保持**不变性（invariance）**（不变性：输入发生某种变化时输出保持不变），同时对**类间差异（inter-class variation）** 保持敏感。

### 1.3 数据驱动方法

**为什么不能直接写规则？** 对数字排序可以写出明确算法，但「识别猫」**没有显而易见的硬编码方式**（课件第 17 页）。历史上人们尝试过先找边缘（例如 Canny 边缘检测，1986）、再找角点、再组合成规则，但这种方法既脆弱（换个物体就要重写），又难以扩展到大量类别。

**数据驱动方法（data-driven approach）**：不直接告诉计算机「猫长什么样」，而是给它大量带标签的例子，让学习算法自己总结规律——就像教小孩认东西一样。

三步流程（课件第 19 页）：

1. **收集**图像与标签组成的数据集；
2. 使用**机器学习（machine learning）**算法**训练（train）**一个分类器；
3. 在**新图像**上**评估（evaluate）**分类器。

对应的编程接口通常是两个函数：

```python
def train(images, labels):
    # 机器学习！
    return model

def predict(model, test_images):
    # 用模型预测标签
    return test_labels
```

评估时最常用的指标是**准确率（accuracy）**：预测正确的样本占全部样本的比例。被比较的「正确答案」称为**真实标签（ground truth）**。

## 2. 最近邻与 k 近邻分类器

### 2.1 最近邻（Nearest Neighbor）

**直觉**：「和谁最像，就是谁」。

**最近邻分类器（Nearest Neighbor classifier）**：

- **训练**：什么也不学，只是**记住所有训练数据和标签**；
- **预测**：对每张测试图像，找到**最相似**的那张训练图像，直接复制其标签。

关键问题是「相似」如何衡量——这需要一个**距离度量（distance metric）**（距离度量：衡量两个样本差异大小的函数，值越小越相似）。

### 2.2 距离度量：L1 与 L2

把图像 $I_1, I_2$ 看作向量，$p$ 遍历所有像素位置。

**L1 距离（曼哈顿距离，Manhattan distance）**：逐像素取差的绝对值再求和。

$$
d_1(I_1, I_2) = \sum_{p} \left| I_1^p - I_2^p \right|
$$

**L2 距离（欧氏距离，Euclidean distance）**：逐像素取差的平方，求和后开根号。

$$
d_2(I_1, I_2) = \sqrt{\sum_{p} \left( I_1^p - I_2^p \right)^2}
$$

#### 🧮 例题：课件中的 4×4 L1 距离

课件第 23 页给出一张 4×4 的测试图像和一张训练图像，逐元素相减取绝对值后得到的差矩阵为：

| 46 | 12 | 14 | 1 |
| --- | --- | --- | --- |
| 82 | 13 | 39 | 33 |
| 12 | 10 | 0 | 30 |
| 2 | 32 | 22 | 108 |

全部相加：$d_1 = 456$。两张图越像，这个值越接近 0。

#### 🧮 例题：L1 与 L2 的几何差异（课件第 31 页）

以原点 $O(0,0)$ 为中心：

- **L1**：$A(1,0)$ 与 $B(0.5,0.5)$ 到 $O$ 的 L1 距离都是 1：$|0-0.5|+|0-0.5| = 1$。所以 L1 下「到原点距离为 1 的点」组成一个**菱形**（像在棋盘格街道上走路）。
- **L2**：$A(1,0)$ 与 $B(1/\sqrt{2}, 1/\sqrt{2})$ 到 $O$ 的 L2 距离都是 1：$\sqrt{1/2+1/2}=1$。所以 L2 下「距离为 1 的点」组成一个**圆**（直线距离，「乌鸦飞过去」）。

| 对比项 | L1（曼哈顿） | L2（欧氏） |
| --- | --- | --- |
| 公式 | $\sum_p \lvert\Delta_p\rvert$ | $\sqrt{\sum_p \Delta_p^2}$ |
| 单位「球」形状 | 菱形 | 圆 |
| 是否依赖坐标系 | 是（旋转坐标轴会改变距离） | 否（旋转不变） |
| 对大差异的态度 | 线性惩罚 | 平方惩罚，**更不能容忍单个大差异**，偏好「许多中等差异」 |
| CIFAR-10 上 1-NN 准确率（笔记） | 约 38.6% | 约 35.4% |

> 💡 **要点**：在只比较大小（找最近邻）时，L2 的开根号可以省略——平方根是单调函数，不改变排序。
>

> 📝 **补充**：L1 和 L2 都是 **p-范数（p-norm）**（p-范数：$\lVert x\rVert_p = (\sum_i |x_i|^p)^{1/p}$，衡量向量大小的一族函数）的特例。课件第 34 页显示，在二维玩具数据上 L1 与 L2 产生的决策边界形状不同：L1 的边界多由与坐标轴平行或成 45° 的线段组成，L2 的边界更「平滑自然」。
>

### 2.3 时间复杂度

课件第 27 页的提问：有 $N$ 个训练样本时，训练和预测各需要多快？

- **训练**：$O(1)$——只存数据（严格地说是存储/引用数据的开销）；
- **预测**：$O(N)$——每张测试图都要和所有训练图比较。

> ⚠️ **易错**：这与我们想要的**正好相反**！实际应用中，我们希望**预测快**（部署在手机、实时系统上），训练慢一点没关系。后面的神经网络正好是「训练很贵、预测很便宜」。
>

加速最近邻搜索有专门的**近似最近邻（Approximate Nearest Neighbor, ANN）**方法（以少量精度换取速度），超出本课范围。课件推荐的高质量实现是 Facebook 的 [FAISS](https://github.com/facebookresearch/faiss)（Johnson et al., “Billion-scale similarity search with GPUs”, 2017）；笔记中还提到了 FLANN。

### 2.4 k 近邻（k-NN）

**直觉**：只听一个邻居的话容易被「坏邻居」带偏，不如问 $k$ 个邻居然后**投票**。

**k 近邻分类器（k-Nearest Neighbors, k-NN）**：找出距离最近的 $k$ 个训练样本，以**多数投票（majority vote）**决定标签。$k=1$ 时就退化为最近邻。

| $k$ 的大小 | 决策边界 | 对离群点 | 风险 |
| --- | --- | --- | --- |
| 小（如 $k=1$） | 锯齿状、破碎 | 敏感：离群点周围会形成「孤岛」 | 过拟合 |
| 大（如 $k=5$） | 更平滑 | 更鲁棒 | 过大时欠拟合，边界被大类「吞掉」 |
- **离群点（outlier）**：与同类大部分样本明显不同的异常样本。
- **决策边界（decision boundary）**：特征空间中把不同预测类别分开的边界。
- 笔记中的示意图里，$k$ 较大时会出现白色/灰色区域，表示**投票平局**、无法确定类别。

>

### 2.5 numpy 实现：向量化距离计算

**向量化（vectorization）**：用矩阵运算代替 Python 循环，让 numpy 底层的高效 C/BLAS 代码完成计算，通常快几十到上百倍。

L2 距离平方的展开式是向量化的关键：

$$
\lVert a - b \rVert_2^2 = \lVert a \rVert_2^2 + \lVert b \rVert_2^2 - 2\, a^\top b
$$

```python
import numpy as np

def compute_l2_distances(X_test, X_train):
    """
    完全向量化的 L2 距离（无任何 Python 循环）
    X_test : (M, D) 每行一张测试图像（已展平）
    X_train: (N, D) 每行一张训练图像
    返回   : (M, N) dists[i, j] = 第 i 张测试图与第 j 张训练图的 L2 距离
    """
    test_sq  = np.sum(X_test ** 2, axis=1, keepdims=True)   # (M, 1)
    train_sq = np.sum(X_train ** 2, axis=1)                  # (N,)
    cross    = X_test @ X_train.T                             # (M, N)
    d2 = test_sq + train_sq - 2 * cross                       # 广播 -> (M, N)
    return np.sqrt(np.maximum(d2, 0))  # 浮点误差可能产生极小负数，先截断为 0

def knn_predict(dists, y_train, k=5):
    """根据距离矩阵做 k-NN 多数投票；y_train 为非负整数标签"""
    nearest = np.argsort(dists, axis=1)[:, :k]    # (M, k) 最近 k 个的下标
    neighbor_labels = y_train[nearest]            # (M, k)
    return np.array([np.bincount(row).argmax() for row in neighbor_labels])
```

> ⚠️ **易错**：
>
> 1. CIFAR-10 像素是 `uint8`，直接相减会**溢出回绕**（如 `np.uint8(2) - np.uint8(5) = 255`）。计算前先 `X.astype(np.float64)`。
> 2. `np.bincount(...).argmax()` 在平局时选择**下标最小**的类别，这只是一种平局处理约定。
> 3. 若只需找最近邻，可以不做 `np.sqrt`（单调性）。

作为对照，笔记中的单循环 L1 版本只需一行核心代码：

```python
distances = np.sum(np.abs(self.Xtr - X[i, :]), axis=1)   # 第 i 张测试图到所有训练图的 L1 距离
```

### 2.6 为什么像素级 kNN 从不用于图像

课件第 48 页的结论：**基于像素距离的 k 近邻从不被用于图像**。

1. **像素距离不包含语义信息**：一张原图与它的「遮挡版」「平移 1 像素版」「调色版」三张图到原图的 L2 距离**完全相同**，但人眼看来差异截然不同。
2. **背景主导**：笔记用 t-SNE（一种把高维数据嵌入到二维以便可视化的方法）展示 CIFAR-10，发现像素距离相近的图像主要是**颜色分布或背景相似**，而非同类物体。例如笔记中马头图像的最近邻是一辆红色汽车，大概是因为都有很强的黑色背景。
3. **维度灾难（curse of dimensionality）**（补充，维度灾难：随着维度升高，要「密集覆盖」空间所需的样本数呈指数增长，且高维空间中距离变得不直观）：$3072$ 维空间中，训练样本永远无法稠密覆盖。
4. **效率**：需要存储整个训练集，预测慢。

> 💡 **要点**：kNN 仍可用作**基线（baseline）**（基线：用来对比的简单参考方法），或用在**学到的特征**上（例如神经网络提取的特征向量做最近邻检索），而不是原始像素上。
>

## 3. 超参数与数据集划分

### 3.1 什么是超参数

**超参数（hyperparameter）**：关于**算法本身**的选择，不是从数据中直接学到的，而是在训练之前由人设定。例如 k-NN 中的 $k$ 和距离度量。与之相对，**参数（parameter）**是模型从数据中学到的量（例如后文线性分类器的 $W$、$b$）。

课件第 36 页强调：超参数的最佳取值**高度依赖具体问题和数据集**，必须逐一尝试，看哪个效果最好。问题是——**在哪份数据上「看效果」？**

### 3.2 四种设置超参数的思路

| 思路 | 做法 | 评价 |
| --- | --- | --- |
| #1 | 选在**训练集**上效果最好的超参数 | ❌ 坏：$k=1$ 在训练集上永远完美 |
| #2 | 选在**测试集**上效果最好的超参数 | ❌ 坏：无法知道算法在**新数据**上的表现。**永远不要这样做！** |
| #3 | 划分为**训练 / 验证 / 测试**；在验证集上选超参数，最后在测试集上评估 | ✅ 更好！ |
| #4 | **交叉验证**：把训练数据分成若干折，轮流做验证并取平均 | ✅ 适合小数据集，深度学习中不常用 |
- **训练集（training set）**：用来学习模型参数的数据。
- **验证集（validation set）**：从训练数据中留出的一部分，作为「假测试集」用来调超参数。
- **测试集（test set）**：只在最后用一次，作为模型**泛化（generalization）**能力（泛化：模型在没见过的新数据上的表现）的无偏估计。

> ⚠️ **易错**：如果在测试集上反复调参，就相当于**把测试集当训练集用了**，测出的性能会**过于乐观**，部署后效果会明显下降。这叫**对测试集过拟合（overfit to the test set）**。**过拟合（overfitting）**：模型过度贴合用于拟合/选择的数据，导致在新数据上表现变差。
>

### 3.3 交叉验证

**k 折交叉验证（k-fold cross-validation）**：

1. 把训练数据平均分成 $k$ 份（**折，fold**）；
2. 每次用其中 1 份做验证、其余 $k-1$ 份做训练；
3. 轮换 $k$ 次，把 $k$ 个验证结果取平均（还可以看标准差）；
4. 选平均表现最好的超参数，最后在测试集上评估一次。

课件第 45 页（以及笔记）给出了 CIFAR-10 上对 $k$ 做 5 折交叉验证的结果图：每个点是一次结果，折线穿过均值，误差棒表示标准差；在该数据上 **$k \approx 7$** 效果最好。

```python
# 5 折交叉验证选 k 的骨架（示例代码）
import numpy as np

num_folds = 5
k_choices = [1, 3, 5, 7, 10, 20, 50]           # 候选值（示例）
X_folds = np.array_split(X_train, num_folds)
y_folds = np.array_split(y_train, num_folds)

results = {}
for k in k_choices:
    accs = []
    for i in range(num_folds):
        X_val, y_val = X_folds[i], y_folds[i]
        X_tr = np.concatenate(X_folds[:i] + X_folds[i+1:])
        y_tr = np.concatenate(y_folds[:i] + y_folds[i+1:])
        dists = compute_l2_distances(X_val, X_tr)
        accs.append(np.mean(knn_predict(dists, y_tr, k) == y_val))
    results[k] = (np.mean(accs), np.std(accs))

best_k = max(results, key=lambda k: results[k][0])
```

### 3.4 实践建议

来自课程笔记的经验：

- 实践中人们更倾向于**单次划分验证集**，因为交叉验证计算开销大（深度学习训练一次就可能很久）。
- 通常把训练数据的 **50%–90%** 用于训练（笔记另一处的经验法则是 70%–90%），其余做验证；超参数越多，验证集应越大。
- 验证集很小（如只有几百个样本）时，用交叉验证更安全；常见 3 折、5 折、10 折。
- 选好超参数后，笔记认为更「干净」的做法是：把验证集视为「已被用掉」，不并回训练集；在测试集上评估一次并报告结果。
- 若在实际中用 kNN：先做**特征归一化（normalization）**（使每个特征均值为 0、方差为 1），高维数据可考虑 **PCA**（主成分分析，一种线性降维方法）等降维手段。

> 💡 **要点**：「测试集是珍贵资源，理想情况下直到最后才碰一次」——这是整个机器学习中最重要的纪律之一。
>

### 3.5 本章小结与自测

> 📌 **本章小结**
>
> - 超参数是算法层面的选择，必须靠实验确定。
> - 不能在训练集或测试集上选超参数；应使用验证集（或交叉验证）。
> - 交叉验证估计更稳定，但成本高，深度学习中较少使用。

## 4. 线性分类器

> 🧱 课件第 55–56 页的比喻：线性分类器像**乐高积木**中最基本的一块。复杂的神经网络（例如 AlexNet [Krizhevsky et al. 2012]、ResNet [He et al. 2015]）中大量使用**线性层（linear layer）**，理解线性分类器是理解神经网络的第一步。
>

### 4.1 参数化方法

kNN 的问题：要存储全部训练数据，预测慢。**参数化方法（parametric approach）**换一种思路：把训练数据的知识**压缩**进一组**参数（parameters）/ 权重（weights）** $W$，训练完后就可以扔掉训练集。

整体框架包含两个部分：

1. **得分函数（score function）**：把原始像素映射为每个类别的得分；
2. **损失函数（loss function）**：衡量得分与真实标签之间的一致程度（第 5 章）。

最简单的得分函数是**线性映射**：

$$
f(x, W) = Wx + b
$$

以 CIFAR-10 为例（课件第 52–54 页）：

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $x$ | $3072 \times 1$ | 展平的 $32\times32\times3$ 图像 |
| $W$ | $10 \times 3072$ | 权重矩阵，每行对应一个类 |
| $b$ | $10 \times 1$ | **偏置（bias）**：与输入无关的每类加性偏移 |
| $f(x,W)$ | $10 \times 1$ | 10 个类别的得分 |
- **CIFAR-10**：10 个类别，50,000 张训练图像，10,000 张测试图像，每张 $32\times32\times3$（Krizhevsky, 2009）。

> 💡 **要点**：
>
> - 一次矩阵乘法 $Wx$ 等价于**并行运行 10 个独立的分类器**，每个分类器是 $W$ 的一行。
> - 预测只需一次矩阵乘法加一次加法，比与所有训练图像比较快得多。
> - 预测时取得分最高的类别作为结果。

### 4.2 代数视角：一个 4 像素的例子

课件第 58–59 页：假设图像只有 4 个像素（单通道），3 个类别（cat / dog / ship）。

输入像素 $x = [56,\ 231,\ 24,\ 2]^\top$，权重与偏置为：

$$
W = \begin{bmatrix} 0.2 & -0.5 & 0.1 & 2.0 \\ 1.5 & 1.3 & 2.1 & 0.0 \\ 0 & 0.25 & 0.2 & -0.3 \end{bmatrix}, \quad
b = \begin{bmatrix} 1.1 \\ 3.2 \\ -1.2 \end{bmatrix}
$$

逐行计算：

- **cat**：$0.2\cdot56 - 0.5\cdot231 + 0.1\cdot24 + 2.0\cdot2 + 1.1 = 11.2 - 115.5 + 2.4 + 4.0 + 1.1 = -96.8$
- **dog**：$1.5\cdot56 + 1.3\cdot231 + 2.1\cdot24 + 0 + 3.2 = 84 + 300.3 + 50.4 + 3.2 = 437.9$
- **ship**：$0\cdot56 + 0.25\cdot231 + 0.2\cdot24 - 0.3\cdot2 = 57.75 + 4.8 - 0.6 = 61.95$，再加 $b_3=-1.2$ 得 $60.75$

> ⚠️ **易错 / 勘误提示**：课件中 ship 的得分写作 $61.95$，这恰好是**未加偏置**时的值；按 $Wx+b$ 加上 $-1.2$ 后应为 $60.75$（本文用 numpy 复核过）。这不影响结论。
>

**结论**：这组权重很糟——输入明明是猫，猫的得分却最低（$-96.8$），模型「坚信」这是狗。我们需要一种方法**衡量**它有多糟并**改进**它，这就是损失函数和优化。

### 4.3 视觉视角：权重即模板

把 $W$ 的每一行重新 reshape 成 $32\times32\times3$ 的图像，就能「看到」每个类别的权重（课件第 61 页）。

**模板匹配（template matching）**：每行权重就是该类的一张**模板（template）/原型（prototype）**，类别得分是模板与输入图像的**内积（inner product / dot product）**（内积：对应元素相乘再求和，衡量两个向量的「对齐」程度）。哪个模板与图像最「吻合」，哪个类得分最高。

从 CIFAR-10 学到的模板可以观察到（笔记）：

- **ship** 模板有大量蓝色——船图通常伴随海水；
- **horse** 模板看起来像一匹**双头马**——数据中既有朝左也有朝右的马，线性分类器只能把两种**模式（mode）**合并到一张模板里；
- **car** 模板偏红——暗示数据集中红色汽车较多；一张模板难以同时覆盖所有颜色和朝向的汽车。

> 💡 **要点**：线性分类器 ≈ 「每类只保留一张**学出来的**图像」的最近邻，并用（负）内积代替 L1/L2 距离。**每类只有一张模板**是它表达能力有限的根本原因；神经网络可以在隐藏层学习多张「子模板」（如「朝左的绿车」「正面的蓝车」）再组合。
>

### 4.4 几何视角：高维空间中的超平面

把每张图像看作 $3072$ 维空间中的一个**点**。每个类别得分 $w_j^\top x + b_j$ 是该空间上的线性函数：

- 满足 $w_j^\top x + b_j = 0$ 的点构成一个**超平面（hyperplane）**（超平面：高维空间中的「平面」，在 2D 中是直线、3D 中是平面）；
- $w_j$ 指向得分增加的方向，超平面一侧得分为正、另一侧为负；
- 改变 $W$ 的一行会**旋转**这个超平面，改变 $b$ 会**平移**它。没有偏置时，所有超平面都被迫穿过原点。

### 4.5 线性分类器的困难情形

课件第 63 页给出三种线性分类器无法正确分开的二维数据：

| 情形 | 类别 1 | 类别 2 | 为何线性不可分 |
| --- | --- | --- | --- |
| 异或型 | 第一、三象限 | 第二、四象限 | 任何一条直线都无法把对角象限分到同一侧（类似 XOR 问题） |
| 环形 | $1 \le \lVert x\rVert_2 \le 2$ 的圆环 | 其余区域 | 类别 1 被类别 2 从内外两侧包围 |
| 多模态 | 三个分离的簇（three modes） | 其余区域 | 一个线性边界只能切出一个半空间 |

> 📝 **补充**：**线性可分（linearly separable）**指存在超平面能把两类完全分开。这些困难情形正是后续**神经网络**（引入非线性）或**特征变换**（例如把直角坐标换成极坐标，环形就变得可分）要解决的问题。
>

### 4.6 偏置技巧与数据预处理

**偏置技巧（bias trick）**（来自笔记）：在 $x$ 末尾补一个常数 1，把 $b$ 作为 $W$ 的最后一列，即可把两组参数合并为一个矩阵：

$$
Wx + b = \begin{bmatrix} W & b \end{bmatrix} \begin{bmatrix} x \\ 1 \end{bmatrix}
$$

对 CIFAR-10：$x$ 变为 $3073\times1$，$W$ 变为 $10\times3073$。

```python
X_aug = np.hstack([X, np.ones((X.shape[0], 1))])   # (N, D) -> (N, D+1)
```

**数据预处理（data preprocessing）**（来自笔记）：

- **零均值中心化（zero-mean centering）**：计算训练集的**均值图像**，从每张图像中减去它，像素大致落在 $[-127, 127]$；
- 进一步可**缩放**到 $[-1, 1]$；
- 笔记指出中心化更重要，其理由要等理解梯度下降的动态后才能解释。

> ⚠️ **易错**：均值图像**只能用训练集计算**，然后同样地应用到验证集和测试集。用全部数据计算均值属于**数据泄露（data leakage）**（数据泄露：评估数据的信息以不正当方式进入训练过程）。
>

## 5. 损失函数

### 5.1 损失函数的作用

课件第 64 页提出：如何选一个好的 $W$？分两步：

1. 定义**损失函数（loss function）**（也叫代价函数 cost function 或目标函数 objective）：量化我们对训练数据上得分的「**不满意程度**」——分类越差，损失越大；
2. 找到一种高效方法，搜索使损失最小的参数——即**优化（optimization）**（下一讲内容）。

给定数据集 $\{(x_i, y_i)\}_{i=1}^{N}$，其中 $x_i$ 是图像、$y_i$ 是（整数）标签，整个数据集上的损失是各样本损失的平均：

$$
L = \frac{1}{N} \sum_{i=1}^{N} L_i\big(f(x_i, W),\, y_i\big)
$$

下文记 $s = f(x_i, W)$ 为得分向量，$s_j$ 为第 $j$ 类得分，$s_{y_i}$ 为正确类得分。

> 📝 **说明**：本次课件（2026 版）在损失部分直接讲解了 **Softmax 分类器**，并在最后一页预告下一讲讲**正则化**和**优化**；课件中**没有**多类 SVM 损失的幻灯片。下面 5.2 节的 SVM 损失与 5.3 节正则化内容来自官方课程笔记，作为补充。
>

**贯穿示例**（以课件中猫 / 车 / 蛙三张图为背景，只看 cat / car / frog 三类得分）：

| 类别 | 猫图（正确类 cat） | 车图（正确类 car） | 蛙图（正确类 frog） |
| --- | --- | --- | --- |
| cat | **3.2** | 1.3 | 2.2 |

### 5.2 多类 SVM 损失（Hinge Loss）

**直觉**：SVM「希望」正确类的得分比每个错误类**至少高出一个间隔（margin）** $\Delta$。只要做到了，就满意（损失为 0）；做不到，差多少罚多少。

**多类支持向量机损失（Multiclass Support Vector Machine loss）**：

$$
L_i = \sum_{j \neq y_i} \max\big(0,\ s_j - s_{y_i} + \Delta\big)
$$

$\max(0, \cdot)$ 这种「在 0 处截断」的函数称为**合页损失（hinge loss）**，因为它的图像像一个合页：在满足间隔之前线性下降，满足后恒为 0。通常取 $\Delta = 1$。

#### 🧮 例题：手算 SVM 损失（$\Delta=1$，数字见上表，示例）

**猫图**（正确类 cat，$s_{y}=3.2$）：

$$
L_1 = \max(0,\ 5.1 - 3.2 + 1) + \max(0,\ -1.7 - 3.2 + 1) = \max(0, 2.9) + \max(0, -3.9) = 2.9 + 0 = 2.9
$$

**车图**（正确类 car，$s_{y}=4.9$）：

$$
L_2 = \max(0,\ 1.3 - 4.9 + 1) + \max(0,\ 2.0 - 4.9 + 1) = 0 + 0 = 0
$$

**蛙图**（正确类 frog，$s_{y}=-3.1$）：

$$
L_3 = \max(0,\ 2.2 + 3.1 + 1) + \max(0,\ 2.5 + 3.1 + 1) = 6.3 + 6.6 = 12.9
$$

**数据集平均损失**：

$$
L = \frac{2.9 + 0 + 12.9}{3} \approx 5.27
$$

> 💡 **要点**：车图虽然 car 得分只比 frog 高 2.9、比 cat 高 3.6，但都已超过 $\Delta=1$，所以 SVM 完全满意，损失为 0。SVM **不在乎超出间隔多少**。
>

**补充知识**：

- **平方合页损失（squared hinge loss / L2-SVM）**：$\max(0,\cdot)^2$，对违反间隔的惩罚更重；标准做法是不平方的版本，但某些数据上平方版更好，可通过验证决定。
- $\Delta$ 可以安全地固定为 1：$W$ 的整体缩放会同比例改变得分差，所以 $\Delta$ 的绝对值没有意义，真正的权衡由正则化强度 $\lambda$ 控制。
- 本形式来自 Weston & Watkins (1999)；另一常见做法是 **一对多（One-vs-All, OVA）**——为每个类单独训练一个二分类 SVM。

### 5.3 正则化

**问题**：假设某个 $W$ 让所有训练样本 $L_i=0$，那么 $2W$、$3W$……也都满足（得分差同比放大），**最优解不唯一**。我们需要表达对某些 $W$ 的偏好。

**正则化（regularization）**：在损失中加入只依赖于权重、不依赖于数据的惩罚项 $R(W)$，防止模型在训练数据上「过于用力」，提升泛化能力。

$$
L = \underbrace{\frac{1}{N}\sum_{i=1}^{N} L_i}_{\text{数据损失 data loss}} + \underbrace{\lambda R(W)}_{\text{正则化损失 regularization loss}}
$$

其中 $\lambda$ 是**正则化强度（regularization strength）**，一个超参数，通常通过验证集确定。

最常用的是 **L2 正则化（L2 regularization）**（又称权重衰减 weight decay）：

$$
R(W) = \sum_k \sum_l W_{k,l}^2
$$

#### 🧮 例题：L2 正则化偏好「分散的小权重」（来自笔记）

输入 $x = [1,1,1,1]$，两个候选权重：

|  | $w_1 = [1,0,0,0]$ | $w_2 = [0.25,0.25,0.25,0.25]$ |
| --- | --- | --- |
| $w^\top x$ | 1 | 1 |
| L2 惩罚 $\sum w^2$ | 1.0 | 0.25 |

两者得分完全相同，但 L2 正则化偏好 $w_2$：它**综合利用所有输入维度**，而不是让少数维度起决定作用，通常泛化更好。

> 📝 **补充**：常见的正则化还有 L1 正则化 $\sum|W_{k,l}|$（倾向于产生稀疏权重）、Elastic Net（L1+L2），以及神经网络中的 Dropout、Batch Normalization、数据增强等——课件最后一页预告下一讲会讲正则化。通常只对 $W$ 而不对偏置 $b$ 做正则化。
>

### 5.4 Softmax 分类器与交叉熵损失

**直觉**：SVM 只把得分当作「分数」；我们更希望把得分解释为**概率**——「我有 87% 的把握这是车」。

**Softmax 分类器（Softmax classifier）**，又称**多项逻辑回归（Multinomial Logistic Regression）**，是二分类**逻辑回归（logistic regression）**向多类的推广。

**Softmax 函数（softmax function）**：把任意实数向量变成每项在 $(0,1)$ 之间、总和为 1 的概率分布：

$$
P(Y = k \mid X = x_i) = \frac{e^{s_k}}{\sum_j e^{s_j}}, \qquad s = f(x_i; W)
$$

两步理解（课件第 70–73 页）：

1. **取指数 $\exp$**：保证「概率 $\ge 0$」，得到**未归一化概率（unnormalized probabilities）**；
2. **归一化（normalize）**：除以总和，保证「概率之和为 1」。

因此原始得分 $s$ 被解释为**未归一化的对数概率（unnormalized log-probabilities）**，也叫 **logits**。

**损失**：最大化正确类的概率，等价于最小化其负对数：

$$
L_i = -\log P(Y = y_i \mid X = x_i) = -\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right) = -s_{y_i} + \log \sum_j e^{s_j}
$$

这就是**交叉熵损失（cross-entropy loss）**，也常被称为负对数似然（negative log-likelihood）。

#### 🧮 例题：手算 Softmax 损失（课件猫图，自然对数）

| 类别 | 得分 $s$（logits） | $e^{s}$（未归一化概率） | 归一化概率 | 正确概率（one-hot） |
| --- | --- | --- | --- | --- |
| cat ✅ | 3.2 | 24.5 | **0.13** | 1.00 |
| car | 5.1 | 164.0 | 0.87 | 0.00 |
| frog | -1.7 | 0.18 | 0.00 | 0.00 |
- 总和：$24.5 + 164.0 + 0.18 \approx 188.7$
- $P(\text{cat}) = 24.5 / 188.7 \approx 0.13$
- $L_1 = -\log(0.13) \approx 2.04$

继续计算另外两张图（示例数字，numpy 复核）：

| 图像 | 正确类概率 | Softmax 损失 $L_i$ | SVM 损失 $L_i$ |
| --- | --- | --- | --- |
| 猫图 | 0.130 | 2.04 | 2.9 |
| 车图 | 0.924 | 0.079 | 0 |
| 蛙图 | 0.0021 | 6.16 | 12.9 |
| **平均** | — | **≈ 2.76** | **≈ 5.27** |

> ⚠️ **易错**：SVM 损失和 Softmax 损失的**数值不能互相比较**，它们只在同一种损失、同一份数据内部有比较意义（笔记明确指出）。
>

**三种等价的理解方式**：

1. **概率视角 / 最大似然估计（Maximum Likelihood Estimation, MLE）**：选择让观测数据出现概率最大的权重（课件第 75 页，细节见 CS229）。最小化负对数似然 = 最大化似然。加上 L2 正则化后，可解释为对 $W$ 施加高斯先验，进行**最大后验估计（Maximum a Posteriori, MAP）**。
2. **信息论视角**：把预测分布 $q$ 与「正确分布」 $p$（课件第 76 页的 one-hot 向量 $[1,0,0]$）对比，**交叉熵（cross-entropy）** $H(p,q) = -\sum_x p(x)\log q(x)$。由于 $H(p,q) = H(p) + D_{KL}(p\Vert q)$ 且 one-hot 分布的熵 $H(p)=0$，最小化交叉熵等价于最小化 **KL 散度（Kullback–Leibler divergence）**（KL 散度：衡量两个概率分布差异的非对称量）。
3. **优化视角**：$-s_{y_i}$ 推高正确类得分，$\log\sum_j e^{s_j}$（「软」最大值）压低最大的错误类得分。

#### 课件中的两个思考题

- ❓ Q1：Softmax 损失 $L_i$ 的最小值和最大值是多少？

    **0**

    - \log 1 = 0

    **$+\infty$**

    **无限逼近**

- ❓ Q2：初始化时所有 $s_j$ 近似相等，假设有 $C$ 类，损失约为多少？

    每类概率约 $1/C$，所以 $L_i = -\log(1/C) = \log C$。当 $C=10$ 时，$L_i = \log 10 \approx 2.3$（课件第 79 页）。

    > 💡 **实用技巧**：这是非常好用的**调试检查（sanity check）**：刚初始化的模型第一次算出的损失若明显偏离 $\log C$，代码多半有 bug。
    >

### 5.5 数值稳定性

$e^{s}$ 在 $s$ 较大时会**上溢（overflow）**（数值超过浮点数可表示的范围，变成 `inf`）。由于分子分母同乘常数 $C$ 不改变结果：

$$
\frac{e^{s_{y_i}}}{\sum_j e^{s_j}} = \frac{e^{s_{y_i} + \log C}}{\sum_j e^{s_j + \log C}}
$$

常取 $\log C = -\max_j s_j$，即**先把每个得分减去最大值**，使最大值为 0：

```python
f = np.array([123, 456, 789])          # 示例：得分很大
p = np.exp(f) / np.sum(np.exp(f))      # ❌ 不安全：exp(789) 溢出为 inf，结果出现 nan

f = f - np.max(f)                      # 变为 [-666, -333, 0]
p = np.exp(f) / np.sum(np.exp(f))      # ✅ 安全且数学上等价
```

> 💡 **要点**：计算损失时最好直接计算 **log-softmax**：$\log p_k = (s_k - m) - \log\sum_j e^{s_j - m}$，避免先算出接近 0 的概率再取 $\log$ 带来的下溢（得到 $-\infty$）。这就是常说的 **log-sum-exp 技巧**。
>

> 📝 **命名说明**：严格来说，SVM 用的是 hinge loss（也称 max-margin loss），Softmax 分类器用的是交叉熵损失；softmax 只是「压缩」函数，「softmax loss」是一种常见但不严谨的简称。
>

### 5.6 SVM vs. Softmax

| 对比维度 | 多类 SVM（hinge loss） | Softmax（交叉熵） |
| --- | --- | --- |
| 得分的解释 | 未校准的类别分数 | 未归一化的对数概率（logits） |
| 损失公式 | $\sum_{j\ne y_i}\max(0, s_j - s_{y_i} + \Delta)$ | $-\log \frac{e^{s_{y_i}}}{\sum_j e^{s_j}}$ |
| 最小 / 最大损失 | $0$ / $+\infty$ | $0$（渐近）/ $+\infty$ |
| 初始化时（得分≈相等）损失 | $(C-1)\Delta$，$\Delta=1$ 时为 $C-1$ | $\log C$ |
| 满足条件后 | 间隔满足即损失为 0，**不再关心** | **永不满足**，总希望正确类概率更高 |
| 输出 | 只能看排序 | 可解释为「置信度」（但受正则化影响） |
| 性质 | 更「局部」：已分好的样本不再影响 | 所有样本都持续产生影响 |
| 实际性能 | 通常与 Softmax 相近 | 通常与 SVM 相近 |

#### 🧮 例题：SVM 满意，Softmax 不满意（笔记示例，第 1 类为正确类，$\Delta=1$）

| 得分 | SVM 损失 | Softmax 损失（numpy 计算） |
| --- | --- | --- |
| $[10, -2, 3]$ | 0 | ≈ 0.00092 |
| $[10, 9, 9]$ | 0 | ≈ 0.55 |
| $[10, -100, -100]$ | 0 | ≈ 0（极小） |

SVM 对三者一视同仁；Softmax 则对 $[10,9,9]$ 给出明显更高的损失。

> ⚠️ **易错**：Softmax 的「概率」并不是严格校准的概率。笔记指出：得分 $[1,-2,0]$ 经 softmax 得 $[0.7, 0.04, 0.26]$；若正则化更强、权重减半为 $[0.5,-1,0]$，则变为 $[0.55, 0.12, 0.33]$——分布更平坦。所以概率的「尖锐程度」依赖于 $\lambda$，应当把它们理解为**相对置信度**。
>

### 5.7 numpy 实现：向量化 SVM 与 Softmax 损失

约定（与作业风格一致）：`X` 形状 `(N, D)`，每行一个样本（可以已包含偏置维）；`W` 形状 `(D, C)`；`y` 形状 `(N,)`，取值 `0..C-1`。因此得分为 `scores = X @ W`，形状 `(N, C)`。

> ⚠️ 注意：这与上文数学写法 $Wx$（$W$ 为 $C\times D$、$x$ 为列向量）互为转置，读代码时别混淆。
>

```python
import numpy as np

def svm_loss_vectorized(W, X, y, reg, delta=1.0):
    """多类 SVM 损失（全向量化，无循环）+ L2 正则化"""
    N = X.shape[0]
    scores = X @ W                                          # (N, C)
    correct = scores[np.arange(N), y][:, None]              # (N, 1) 正确类得分
    margins = np.maximum(0, scores - correct + delta)       # (N, C)
    margins[np.arange(N), y] = 0                            # 正确类本身不计入（否则每项多加 delta）
    data_loss = margins.sum() / N
    return data_loss + reg * np.sum(W * W)

def softmax_loss_vectorized(W, X, y, reg):
    """Softmax / 交叉熵损失（全向量化，数值稳定）+ L2 正则化"""
    N = X.shape[0]
    scores = X @ W                                          # (N, C)
    scores = scores - scores.max(axis=1, keepdims=True)     # 数值稳定：每行减去最大值
    log_probs = scores - np.log(np.exp(scores).sum(axis=1, keepdims=True))  # log-softmax
    data_loss = -log_probs[np.arange(N), y].mean()
    return data_loss + reg * np.sum(W * W)

# —— 用 5.1 节的例子自检：令 X 为得分矩阵、W 为单位阵，则 X @ W 就是得分本身 ——
S = np.array([[3.2, 5.1, -1.7],    # 猫图
              [1.3, 4.9,  2.0],    # 车图
              [2.2, 2.5, -3.1]])   # 蛙图
y = np.array([0, 1, 2])
print(svm_loss_vectorized(np.eye(3), S, y, reg=0.0))      # ≈ 5.267
print(softmax_loss_vectorized(np.eye(3), S, y, reg=0.0))  # ≈ 2.759
```

> 💡 **要点**：`scores[np.arange(N), y]` 是**花式索引（fancy indexing）**：一次性取出每一行中正确类所在列的元素，是实现向量化损失的关键技巧。
>

$$
\underbrace{x}_{\text{图像}} \xrightarrow{\ f(x,W)=Wx+b\ } \underbrace{s}_{\text{得分}} \xrightarrow{\ \text{SVM / Softmax}\ } \underbrace{L_i}_{\text{单样本损失}} \xrightarrow{\ \text{平均} + \lambda R(W)\ } \underbrace{L}_{\text{总损失}} \xrightarrow{\ \text{优化}\ } \text{更好的 } W
$$

| L2 / 欧氏距离 | L2 / Euclidean distance | 差的平方和开根号 |
| 决策边界 | Decision boundary | 不同预测类别区域之间的分界 |
| 近似最近邻 | Approximate Nearest Neighbor (ANN) | 牺牲少量精度换取速度的近邻检索 |
| 维度灾难 | Curse of dimensionality | 高维空间中样本稀疏、距离不直观的现象 |
| 超参数 | Hyperparameter | 训练前人为设定的算法选择，如 $k$、$\lambda$ |
| 参数 / 权重 | Parameters / Weights | 模型从数据中学到的量，如 $W$ |
| 训练 / 验证 / 测试集 | Train / Validation / Test set | 分别用于学参数、调超参数、最终评估 |
| 交叉验证 | Cross-validation | 轮流以各折为验证集并取平均 |
| 过拟合 | Overfitting | 过度拟合已见数据，在新数据上表现差 |
| 泛化 | Generalization | 在未见过数据上的表现能力 |
| 向量化 | Vectorization | 用数组运算代替显式循环 |
| 参数化方法 | Parametric approach | 把知识存入固定数量的参数 |
| 得分函数 | Score function | 输入 → 各类得分的映射 |
| 线性分类器 | Linear classifier | 得分函数为 $Wx+b$ 的分类器 |
| 偏置 | Bias | 与输入无关的加性项 $b$ |
| 偏置技巧 | Bias trick | 输入补 1，把 $b$ 并入 $W$ |
| 模板匹配 | Template matching | 用内积比较输入与各类模板 |
| 超平面 | Hyperplane | 高维空间中的「平面」，线性分类器的决策面 |
| 线性可分 | Linearly separable | 存在超平面完全分开各类 |
| 零均值中心化 | Zero-mean centering | 减去训练集均值图像 |
| 损失函数 | Loss function | 量化预测与标签的不一致程度 |
| 多类 SVM 损失 | Multiclass SVM loss | 要求正确类得分高出错误类至少 $\Delta$ |
| 合页损失 | Hinge loss | $\max(0, \cdot)$ 形式的损失 |
| 间隔 | Margin ($\Delta$) | SVM 要求的最小得分差 |
| 正则化 | Regularization | 对权重加惩罚以偏好简单模型、改善泛化 |
| 正则化强度 | Regularization strength ($\lambda$) | 正则化项的权重系数 |
| Softmax 函数 | Softmax function | 把实数向量变为概率分布 |
| Logits | Logits | 未归一化的对数概率（原始得分） |
| 交叉熵损失 | Cross-entropy loss | $-\log$ 正确类概率 |
| 多项逻辑回归 | Multinomial logistic regression | Softmax 分类器的别名 |
| 最大似然估计 | Maximum Likelihood Estimation (MLE) | 选使观测数据概率最大的参数 |
| 最大后验估计 | Maximum a Posteriori (MAP) | 在 MLE 基础上加入参数先验 |
| KL 散度 | Kullback–Leibler divergence | 衡量两个分布差异的量 |
| 数值稳定性 | Numerical stability | 避免上溢/下溢导致的计算错误 |
| 优化 | Optimization | 寻找使损失最小的参数 |
