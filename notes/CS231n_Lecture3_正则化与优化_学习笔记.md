## 0. 课前回顾：线性分类器

先快速回忆上一讲的“前情提要”👇

**图像分类**：输入一张图，输出一个类别标签（猫、车、青蛙……）。难点在于同一只猫可能因为**视角、光照、形变、遮挡、背景杂乱、类内差异**而看起来完全不同。

**数据驱动方法**：不手写规则，而是“喂数据 → 训练模型 → 在新图上预测”。数据通常分成三份：

| 数据集 | 作用 | 类比 |
|---|---|---|
| 训练集 Train | 学习参数 `W` | 课本 + 练习题 |
| 验证集 Validation | 挑选超参数（如 λ、学习率） | 模拟考 |
| 测试集 Test | 最后只用一次，评估真实水平 | 高考 |

**线性分类器**：

$$
f(x, W) = Wx + b
$$

以 CIFAR-10 为例：一张图是 32×32×3 = **3072** 个数字，拉成一列向量 `x`；`W` 的形状是 10×3072，输出 **10 个类别分数**。

理解它的三个视角：

- 🔢 **代数视角**：就是矩阵乘法 + 偏置
- 🖼️ **模板视角**：`W` 的每一行像一张“类别模板”，分数 = 图片与模板的相似度
- 📐 **几何视角**：每个类别在高维空间中画一个“超平面”把空间切开

> 💡 **本讲的出发点**：`W` 一开始是随机的，分数乱七八糟。我们需要（1）一个衡量“乱”程度的标准，（2）一个让它“不乱”的方法。

## 1. 损失函数：给模型打分

### 1.1 什么是损失函数？

> 📖 **损失函数（Loss Function）**：一个衡量“模型预测有多糟糕”的数字。**越小越好**。

对 N 个训练样本，整体损失就是每个样本损失的平均值：

$$
L = \frac{1}{N}\sum_{i=1}^{N} L_i\big(f(x_i, W),\ y_i\big)
$$

- `x_i`：第 i 张图片
- `y_i`：它的真实标签
- `L_i`：模型在这张图上“错得有多离谱”

### 1.2 课件中的小例子

3 张训练图，3 个类别，当前 `W` 给出的分数如下（**粗体是正确类别**）：

| 类别 \ 图片 | 🐱 猫图 | 🚗 车图 | 🐸 蛙图 |
|---|:---:|:---:|:---:|
| cat | **3.2** | 1.3 | 2.2 |
| car | 5.1 | **4.9** | 2.5 |
| frog | -1.7 | 2.0 | **-3.1** |

一眼可见：猫图被认成了车（5.1 > 3.2），蛙图更是错得离谱。下面两种损失函数会把这种“糟糕”量化。

### 1.3 Softmax 损失（交叉熵损失）⭐ 最常用

**思路**：把分数变成“概率”，然后看正确类别的概率有多高。

三步走：

1. **取指数** `e^s`：让所有分数变成正数
2. **归一化**：除以总和，让它们加起来 = 1（这一步叫 **Softmax**）
3. **取负对数**：`L_i = -log(正确类别的概率)`

$$
L_i = -\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right)
$$

以猫图为例：

| | 分数 s | e^s | 概率 |
|---|:---:|:---:|:---:|
| cat | 3.2 | 24.5 | **0.13** |
| car | 5.1 | 164.0 | 0.87 |
| frog | -1.7 | 0.18 | 0.00 |

`L_i = -log(0.13) ≈ 2.04`

> 💡 **直觉**：正确类别概率 = 1 → 损失 = 0（完美）；概率越接近 0 → 损失越趋向无穷大（严重惩罚）。

### 1.4 SVM 损失（Hinge 合页损失）

**思路**：正确类别的分数要比其他类别**至少高出一个安全边界（margin = 1）**，做到了就不罚，没做到就按差距罚。

$$
L_i = \sum_{j \neq y_i} \max(0,\ s_j - s_{y_i} + 1)
$$

| 图片 | 计算过程 | 损失 |
|---|---|:---:|
| 🐱 猫 | max(0, 5.1−3.2+1) + max(0, −1.7−3.2+1) = 2.9 + 0 | **2.9** |
| 🚗 车 | max(0, 1.3−4.9+1) + max(0, 2.0−4.9+1) = 0 + 0 | **0** |
| 🐸 蛙 | max(0, 2.2+3.1+1) + max(0, 2.5+3.1+1) = 6.3 + 6.6 | **12.9** |

平均损失 L = (2.9 + 0 + 12.9) / 3 ≈ **5.27**

### 1.5 两者对比

| | Softmax | SVM |
|---|---|---|
| 输出含义 | 概率（可解释） | 只是分数 |
| 什么时候满意 | 永不完全满足，总想把正确概率推向 1 | 超过 margin 就“躺平”，损失为 0 |
| 现代深度学习 | ✅ 主流 | 较少使用 |

## 2. 正则化：别把题背死

### 2.1 一个奇怪的问题

假设我们找到某个 `W` 让 SVM 损失 L = 0。那么 `2W` 呢？

所有分数都翻倍，差距也翻倍，依然满足 margin → **`2W` 的损失也是 0！**（课件里车图的例子：W 时损失 0，2W 时还是 0。）

> ❓ 那么多个 `W` 都“满分”，该选哪一个？——**正则化帮我们做选择。**

### 2.2 正则化的公式

$$
L(W) = \underbrace{\frac{1}{N}\sum_i L_i}_{\text{数据损失：拟合训练数据}} + \underbrace{\lambda R(W)}_{\text{正则项：让模型简单些}}
$$

- **数据损失**：模型预测要和训练数据对得上
- **正则项**：防止模型在训练数据上“学得太好”
- **λ（lambda）**：正则化强度，是个**超参数**，用验证集来挑

### 2.3 为什么要“简单”？——奥卡姆剃刀 🪒

> **奥卡姆剃刀（Occam's Razor）**：在多个能解释现象的假设中，选择最简单的那个。

课件里的图：几个蓝点，

- 模型 f1：一条弯弯曲曲、穿过每一个点的曲线 → 训练误差 0，但碰到新数据（绿点）就翻车
- 模型 f2：一条简单直线 → 虽然不完美，但对新数据预测得更好

这就是 **过拟合（Overfitting）**：像学生把练习题答案背下来，换道题就不会了。正则化就是让学生“理解规律而不是死记硬背”。

### 2.4 常见的正则化方法

**简单款（直接加在损失上）**

| 名称 | 公式 | 偏好 |
|---|---|---|
| **L2 正则** | R(W) = Σ W² | 权重**小而分散**，大家都有点贡献 |
| **L1 正则** | R(W) = Σ \|W\| | 权重**稀疏**，很多直接变 0 |
| **Elastic Net** | Σ (β·W² + \|W\|) | L1 + L2 的组合 |

**复杂款（以后的课会讲）**：Dropout、Batch Normalization、Stochastic Depth、Fractional Pooling 等。

### 2.5 L1 vs L2 的经典例子

输入 `x = [1, 1, 1, 1]`，两组权重：

- `w1 = [1, 0, 0, 0]`
- `w2 = [0.25, 0.25, 0.25, 0.25]`

两者与 x 的点积都 = **1**，数据损失完全一样。但：

| | L2 正则 Σw² | L1 正则 Σ\|w\| |
|---|:---:|:---:|
| w1 | 1 | 1 |
| w2 | **0.25** ✅ | 1 |

- **L2 更喜欢 w2**：“把注意力分散到所有像素上”，不依赖单一特征，更稳健
- **L1 喜欢稀疏解**：倾向于像 w1 那样只保留少数重要特征（本例两者 L1 相同，但在一般情况下 L1 会把权重推向 0）

> 🎯 **正则化的三大作用**
> 1. 表达我们对模型的**偏好**（比如“权重要分散”）
> 2. 让模型更**简单**，在测试数据上**泛化**更好
> 3. 给损失函数增加“曲率”，让**优化更顺利**

## 3. 优化：蒙着眼睛下山

### 3.1 下山的比喻 🏔️

想象损失函数是一片连绵的山谷：

- **位置** = 当前的权重 `W`
- **海拔** = 损失 `L(W)`
- **目标** = 走到谷底（损失最小）

但你**蒙着眼睛**——看不到全貌（`W` 有几万甚至几十亿维），只能用脚感受**脚下的坡度**。

> 📚 [CS231n 优化笔记](https://cs231n.github.io/optimization-1/) 里还展示了如何“看”这座山：沿着一个随机方向切一刀，画出损失随步长变化的 1D 曲线，或沿两个方向画 2D 热力图。对 SVM 来说，这个地形是**碗状（凸函数）**的；到了神经网络就会变得坑坑洼洼。

### 3.2 策略 1：随机搜索（反面教材）❌

```python
bestloss = float("inf")
for num in range(1000):
    W = np.random.randn(10, 3073) * 0.0001   # 随机生成一个 W
    loss = L(X_train, Y_train, W)
    if loss < bestloss:                      # 记录最好的
        bestloss, bestW = loss, W
```

在 CIFAR-10 上的准确率：**15.5%**（瞎猜是 10%），而当今最好的方法约 **99.7%**。

> 优化笔记里还有个改进版“**随机局部搜索**”：从当前位置随机迈一小步，变好了才走。能到约 21.4%，但仍然低效又浪费。

### 3.3 策略 2：顺着坡往下走 ✅

一维时，坡度就是**导数**：

$$
\frac{df(x)}{dx} = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

多维时，把每个方向的坡度（偏导数）排成一个向量，叫 **梯度（Gradient）**，记作 ∇L。

> 🔑 **关键事实**
> - 梯度指向**上升最快**的方向
> - 所以 **负梯度** 就是**下降最快**的方向（最陡下降）
> - 某方向的坡度 = 该方向与梯度的点积

### 3.4 怎么算梯度？两种方法

**① 数值梯度（Numerical Gradient）**：真的“挪一点点”试试看

课件中的例子：

| 操作 | 损失 | 该维梯度 |
|---|:---:|:---:|
| 原始 W = [0.34, -1.11, 0.78, …] | 1.25347 | — |
| 第 1 维 +0.0001 → 0.3401 | 1.25322 | (1.25322−1.25347)/0.0001 = **−2.5** |
| 第 2 维 +0.0001 → −1.1099 | 1.25353 | **0.6** |
| 第 3 维 +0.0001 → 0.7801 | 1.25347 | **0** |

要对**每一维**都试一遍 → 几百万个参数就要算几百万次损失，**太慢**，而且只是**近似值**。

> 💡 优化笔记提示：实际中用**中心差分** `[f(x+h) − f(x−h)] / 2h` 更准确。

**② 解析梯度（Analytic Gradient）**：用微积分直接推出公式

| | 数值梯度 | 解析梯度 |
|---|---|---|
| 精度 | 近似 | 精确 ✅ |
| 速度 | 慢 | 快 ✅ |
| 写代码 | 简单不易错 ✅ | 容易写错 |

> 🛠️ **实践做法**：平时用解析梯度，再用数值梯度做 **梯度检查（Gradient Check）**，确认公式没写错。PyTorch 等框架会自动算梯度（下一讲的**反向传播**就是原理）。

## 4. 梯度下降与 SGD

### 4.1 梯度下降（Gradient Descent）

整个算法只有三行：

```python
while True:
    weights_grad = evaluate_gradient(loss_fun, data, weights)
    weights += -step_size * weights_grad   # 沿负梯度走一步
```

需要设定的超参数：

- **初始化方法**：从哪里开始下山
- **步长 / 学习率（learning rate）**：每一步迈多大
- **迭代次数**：走多少步

### 4.2 随机梯度下降（SGD）

问题：完整的损失要对**全部 N 个样本**求和。N 可能是几百万（ImageNet 约 130 万），每走一步都要算全部数据，太贵了！

解决：每次随机抽一小批（**minibatch**），用它来**估计**梯度。

```python
while True:
    data_batch = sample_training_data(data, 256)   # 随机抽 256 个样本
    weights_grad = evaluate_gradient(loss_fun, data_batch, weights)
    weights += -step_size * weights_grad
```

> 📏 常用 batch size：**32 / 64 / 128 / 256**（常取 2 的幂，方便 GPU 计算）。
> 🗳️ **类比**：就像民意调查，不用问全国每个人，随机抽样几百人就能大致估计结果。

## 5. SGD 的三大烦恼

### 烦恼 ① 病态条件：之字形前进 〰️

如果山谷是一条**又窄又长的峡谷**——一个方向很陡、另一个方向很平：

- 陡的方向：来回震荡 ↔️
- 平的方向：慢慢挪 🐢

结果就是 **之字形（zigzag）** 前进，又慢又抖。

> 📖 **条件数（Condition Number）**：Hessian 矩阵最大与最小奇异值之比，衡量“地形有多扁”。条件数越大，SGD 越难受。

### 烦恼 ② 局部最小值与鞍点 🐴

- **局部最小值**：小坑里，四周都是上坡，梯度为 0，卡住
- **鞍点（Saddle Point）**：像马鞍——一个方向上坡、另一个方向下坡，梯度也为 0，例如 `f(x, y) = x² − y²` 在原点

> 💡 在**高维空间**中，**鞍点比局部最小值常见得多**（几百万个方向都是上坡的概率极低）。而且鞍点**附近**梯度很小，SGD 会走得非常慢。

### 烦恼 ③ 梯度有噪声 🎲

minibatch 只是样本的一部分，算出的梯度带有随机性，所以 SGD 走的路线是**摇摇晃晃**的。

## 6. 优化器进化史：Momentum → Adam → AdamW

> 🧩 一句话概括：**后面的优化器都是在 SGD 上打补丁**，用“历史信息”让每一步走得更聪明。

### 6.1 SGD + Momentum（动量）⚽

**比喻**：一个从山上滚下的球，有**惯性**。

```python
vx = 0
while True:
    dx = compute_gradient(x)
    vx = rho * vx + dx          # 速度 = 摩擦后的旧速度 + 新梯度
    x -= learning_rate * vx     # 按速度移动
```

- `rho`（ρ）像**摩擦系数**，常取 **0.9 或 0.99**
- **速度**是过去梯度的“滑动平均”

**它如何解决三大烦恼**：

| 烦恼 | Momentum 的效果 |
|---|---|
| 局部最小 / 鞍点 | 有惯性，能**冲过去** |
| 之字形 | 来回的分量互相抵消，前进的分量不断累积 |
| 噪声 | 平均之后更平稳 |

> 🔭 **Nesterov 动量**（课件附录）：先按速度“往前看一步”，在那个位置算梯度再修正，通常更稳。

### 6.2 AdaGrad：每个参数有自己的步长 📏

```python
grad_squared = 0
while True:
    dx = compute_gradient(x)
    grad_squared += dx * dx
    x -= learning_rate * dx / (np.sqrt(grad_squared) + 1e-7)
```

- 陡的方向（梯度大）→ 除以大数 → **步子变小**（抑制震荡）
- 平的方向（梯度小）→ 除以小数 → **步子变大**（加速前进）

⚠️ 问题：`grad_squared` 只增不减，时间一长**步长衰减到 0**，走不动了。

### 6.3 RMSProp：“会遗忘的 AdaGrad” 🧽

```python
grad_squared = 0
while True:
    dx = compute_gradient(x)
    grad_squared = decay_rate * grad_squared + (1 - decay_rate) * dx * dx
    x -= learning_rate * dx / (np.sqrt(grad_squared) + 1e-7)
```

把“累加”换成“滑动平均”（Leaky），旧的历史会慢慢被遗忘，步长不会一直缩到 0。

### 6.4 Adam：Momentum + RMSProp 的合体 🦸

```python
first_moment = 0
second_moment = 0
for t in range(1, num_iterations):
    dx = compute_gradient(x)
    first_moment  = beta1 * first_moment  + (1 - beta1) * dx        # 类似 Momentum
    second_moment = beta2 * second_moment + (1 - beta2) * dx * dx   # 类似 RMSProp
    first_unbias  = first_moment  / (1 - beta1 ** t)                # 偏差修正
    second_unbias = second_moment / (1 - beta2 ** t)
    x -= learning_rate * first_unbias / (np.sqrt(second_unbias) + 1e-7)
```

> ❓ **为什么要偏差修正（Bias Correction）？**
> 一开始两个“动量”都从 0 起步，前几步会被严重低估。特别是 `second_moment` 很小，作为分母会让第一步迈得**巨大**。除以 `(1 − β^t)` 就能把它们“放大回正常水平”；随着 t 变大，这个修正逐渐趋近 1，自动消失。

✅ **推荐默认值**：`beta1 = 0.9`，`beta2 = 0.999`，`learning_rate = 1e-3 或 5e-4`——很多模型直接用就能跑得不错。

### 6.5 AdamW：把权重衰减“拎出来” 🔧

在 Adam 里，如果把 L2 正则直接加到梯度中，它也会被 `second_moment` 除掉，**不同参数受到的正则强度不一样**，效果走样。

**AdamW** 的做法：动量正常算，**最后单独**做一次权重衰减：

```
x -= lr * ( first_unbias / sqrt(second_unbias)  +  weight_decay * x )
```

> 📈 fast.ai 等实验表明 AdamW 泛化更好，现在已经是训练 Transformer、大模型的**标配**。

### 6.6 一张表看懂优化器

| 优化器 | 一句话 | 用了“动量”？ | 自适应步长？ | 关键超参 |
|---|---|:---:|:---:|---|
| SGD | 沿负梯度走 | ❌ | ❌ | lr |
| SGD + Momentum | 加上惯性 | ✅ | ❌ | lr, ρ |
| AdaGrad | 按历史梯度缩放步长 | ❌ | ✅（会衰减到 0） | lr |
| RMSProp | 会遗忘的 AdaGrad | ❌ | ✅ | lr, decay_rate |
| **Adam** | Momentum + RMSProp + 偏差修正 | ✅ | ✅ | lr, β1, β2 |
| **AdamW** | Adam + 解耦的权重衰减 | ✅ | ✅ | lr, β1, β2, wd |

## 7. 学习率：最重要的超参数

### 7.1 学习率该多大？🎯

看训练时的 loss 曲线：

| 学习率 | 曲线表现 |
|---|---|
| 🔥 太高 | loss 爆炸（甚至变成 NaN） |
| 🔥 偏高 | 一开始降得快，但很早就停在较高的位置 |
| 🐢 太低 | 下降得非常慢 |
| ✅ 刚好 | 稳定下降，最终最低 |

> 答案：**以上全都要**——开始用大一点的学习率快速前进，后面再慢慢减小。这就是**学习率调度（Learning Rate Schedule）**。

### 7.2 常见调度方式

| 方式 | 规则 | 备注 |
|---|---|---|
| **阶梯衰减 Step** | 到固定 epoch 乘以 0.1 | ResNet：第 30、60、90 epoch 各乘 0.1 |
| **余弦 Cosine** | α_t = ½ α₀ (1 + cos(tπ/T)) | 平滑下降，很流行 |
| **线性 Linear** | α_t = α₀ (1 − t/T) | 简单好用 |
| **平方根倒数 Inverse sqrt** | α_t = α₀ / √t | Transformer 原论文使用 |
| **线性预热 Warmup** | 前约 5000 步从 0 线性升到 α₀ | 防止一开始学习率过大导致发散，常与上述方式组合 |

> 📌 **经验法则**：batch size 扩大 N 倍，学习率也大约扩大 N 倍。
> 📖 **Epoch**：把整个训练集完整过一遍叫 1 个 epoch。

## 8. 二阶优化（了解即可）

| | 一阶优化 | 二阶优化 |
|---|---|---|
| 用到什么 | 梯度（坡度） | 梯度 + **Hessian**（曲率，坡度的变化） |
| 近似方式 | 用一条**直线**近似地形 | 用一个**碗（二次曲面）**近似地形 |
| 怎么走 | 沿坡往下迈一步 | 直接跳到碗底 |

牛顿法更新：θ* = θ₀ − H⁻¹ ∇J(θ₀)，**连学习率都不需要**！

**但是**：参数有 N 个，Hessian 就有 N² 个元素，求逆要 O(N³) —— 几百万参数根本存不下、算不动 🤯

- **BFGS / L-BFGS**：用近似方法绕开完整 Hessian。L-BFGS 在**全批量**（数据少、无噪声）时效果很好，但在 **minibatch** 的随机场景下表现不佳，所以深度学习里很少用。

## 9. 实战建议 & 展望神经网络

### 9.1 课件的实战建议 ✅

> 1. **Adam / AdamW 是很好的默认选择**，即使学习率固定也常常能用
> 2. **SGD + Momentum** 有时能超过 Adam，但更需要调学习率和调度
> 3. 如果能做**全批量**更新，可以试试 **L-BFGS**（记得去掉噪声来源）

### 9.2 展望：从线性分类器到神经网络 🧠

线性分类器只能画“直线”边界。如果数据是一个圈套着一个圈（如红点在中间、蓝点在外圈），直线怎么都分不开。

**办法**：先做一个**特征变换**——比如把直角坐标 (x, y) 转成极坐标 (r, θ)，圆圈就变成了可以用直线分开的两条带！

神经网络就是**自动学习**这种变换：

$$
f = W_2 \max(0,\ W_1 x)
$$

- `max(0, ·)` 叫 **ReLU**，是一种**非线性激活函数**
- ⚠️ 如果去掉它，`W2 · W1 x` 仍然只是一个线性函数——叠多少层都白叠！
- 这样的网络叫**全连接网络 / 多层感知机（MLP）**

> 🔜 **下一讲**：反向传播（Backpropagation）——怎样为这种复杂的函数高效地计算梯度。

### A.4 广播（Broadcasting）⭐

形状不同的数组也能直接运算，NumPy 会自动“复制扩展”小的那个：

### A.5 小实战：用 NumPy 写 Softmax 损失

```python
import numpy as np

scores = np.array([3.2, 5.1, -1.7])   # 猫图的分数
y = 0                                  # 正确类别：cat

shifted = scores - np.max(scores)      # 减去最大值，防止 exp 溢出（数值稳定技巧）
probs = np.exp(shifted) / np.sum(np.exp(shifted))
loss = -np.log(probs[y])

print(probs.round(2))   # [0.13 0.87 0.  ]
print(round(loss, 2))   # 2.04
```

### A.6 小实战：数值梯度 + 梯度下降

```python
import numpy as np

def f(w):                       # 一个简单的“碗”：最低点在 w = [3, -2]
    return (w[0] - 3) ** 2 + (w[1] + 2) ** 2

def numerical_grad(f, w, h=1e-5):
    grad = np.zeros_like(w)
    for i in range(w.size):     # 每一维挪一点点（中心差分）
        old = w[i]
        w[i] = old + h; fp = f(w)
        w[i] = old - h; fm = f(w)
        w[i] = old
        grad[i] = (fp - fm) / (2 * h)
    return grad

w = np.array([0.0, 0.0])
lr = 0.1
for step in range(50):
    w -= lr * numerical_grad(f, w)
print(w.round(3))               # 约 [ 3. -2.]  —— 成功走到谷底 🎉
```

> 🧪 动手试试：把 `lr` 改成 `1.1`，看看会发生什么？（提示：学习率太大，loss 会爆炸）

## 📝 自测小练习

<details>
<summary><b>Q1.</b> 刚初始化时 W 很小，所有分数约等于 0。有 C 个类别，Softmax 损失大约是多少？</summary>

每个类别概率约为 1/C，所以损失 ≈ −log(1/C) = **log C**。CIFAR-10 中约为 log 10 ≈ 2.3。训练刚开始时可以用它检查代码有没有写错。
</details>

<details>
<summary><b>Q2.</b> 为什么 L2 正则会偏好 w2 = [0.25, 0.25, 0.25, 0.25] 而不是 w1 = [1, 0, 0, 0]？</summary>

两者数据损失一样，但 L2 惩罚 Σw²：w1 为 1，w2 只有 0.25。L2 喜欢“分散”的权重，让模型同时参考所有输入特征。
</details>

<details>
<summary><b>Q3.</b> SGD 相比完整梯度下降的优点和缺点各是什么？</summary>

优点：每步计算量小、速度快，能处理海量数据；缺点：梯度有噪声，路线摇晃。
</details>

<details>
<summary><b>Q4.</b> Adam 是由哪两种方法组合而成的？</summary>

**Momentum**（一阶矩，提供惯性）+ **RMSProp**（二阶矩，提供每个参数的自适应步长），再加上偏差修正。
</details>

<details>
<summary><b>Q5.</b> 神经网络 f = W₂ max(0, W₁x) 如果去掉 max，会怎样？</summary>

变成 W₂W₁x，本质上还是一个矩阵乘 x，即线性分类器，堆再多层也没用。
</details>
