## 1. 先建立全局地图

### 1.1 什么是生成模型？

假设你看到很多猫的照片，却没有一张“所有猫的总表”。一个好的生成模型从这些样本中学到猫图片的统计规律，然后能产生**新的、看起来合理的猫图片**。

这里有两件不同的事：

- **训练（training）**：用已有样本调整模型参数，让模型学到数据规律。
- **生成 / 采样（generation / sampling）**：训练结束后，给模型随机输入，得到新样本。

直观图景：

```text
真实数据集 ──训练──> 生成模型
                         │
                     随机输入
                         ↓
                    新的样本
```

生成模型的目标通常不是精确复原训练集中的某张照片，而是让生成样本的**整体分布**接近真实数据的分布。当然，训练数据不足或模型过拟合时也可能出现记忆与泄露，应另行评估。

### 1.2 判别和生成有什么区别？

| 任务 | 典型输入 → 输出 | 概率视角 | 例子 |
|---|---|---|---|
| 判别 / 分类 | 图片 `x` → 标签 `y` | `p(y∣x)` | 这张图有多大概率是猫？ |
| 无条件生成 | 随机数 → 样本 `x` | 学习 `p(x)` | 生成一张合理图片 |
| 条件生成 | 条件 `y` + 随机数 → `x` | 学习 `p(x∣y)` | 根据“戴帽子的猫”生成图片 |

`p(y∣x)` 与 `p(x∣y)` 方向不同：前者读图判断标签；后者在给定标签或文本后生成图。一个条件可能对应很多张合理图片，随机性帮助模型产生多样结果。

### 1.3 本讲四条路线

| 路线 | 核心直觉 | 如何生成 | 关键词 |
|---|---|---|---|
| 自回归（Autoregressive） | 将整体拆成一串局部预测 | 从左到右逐个生成 token | 条件概率、序列 |
| VAE | 把数据压到潜空间，再从中解码 | 抽潜变量，再用解码器生成 | 编码器、解码器、ELBO |
| GAN | 用判别器给生成器提供训练信号 | 随机向量经生成器，通常一次前向计算 | 对抗、minimax |
| 扩散 / 流匹配 | 学习从噪声通向数据的逐步变换 | 从噪声出发，多次更新 | 噪声、时间、速度场 |

它们不必互斥：例如潜空间扩散可使用 VAE 类编码器/解码器；编码器/解码器训练也可能借助对抗损失。课件 pp. 3–9、35、96、119–120。

## 2. 补齐基础概念

### 2.1 分布、样本与概率密度

**数据分布** `p_data(x)` 是一个理想化的描述：它给不同样本分配可能性。真实分布通常未知；训练集只是从现实中收集到的有限样本。

- `x ~ p_data`：从真实数据分布中抽一个样本。实践中常用训练集里随机抽取的数据近似。
- `z ~ N(0, I)`：从标准多维高斯分布抽一个随机向量。`0` 是均值向量，`I` 是单位矩阵，意味着各坐标方差为 1、彼此不相关。
- `E[·]`：期望，可先理解成“对大量可能情况求加权平均”。实践中通常以一个 **batch（小批量）** 的平均近似。
- `p(x)` 若描述连续变量，通常是**概率密度**，不是“某个精确点的概率”。密度可以大于 1；整个空间上的积分才为 1。

一张 `256×256×3` 的彩色图可以看成包含 `256×256×3=196,608` 个数字的长向量；每个数字通常对应一个颜色通道的像素值。图像的“分布”因此处在非常高维的空间。

### 2.2 神经网络、参数与优化

神经网络可以视为带可学习旋钮的函数 `f_θ`：输入某些数字，输出另一些数字；`θ`（theta）代表所有可训练参数。

- **损失函数（loss）**：用一个数衡量当前预测有多不理想。越小通常越好，但不同模型的损失不一定能直接横向比较。
- **梯度（gradient）**：损失对参数的变化方向及敏感程度。训练用**反向传播（backpropagation）**计算梯度。
- **梯度下降**：根据梯度反方向微调参数；**学习率**决定调整幅度。
- **推理 / 前向计算（inference / forward pass）**：固定参数，计算网络输出。训练一般包括前向计算、算损失、反向传播和参数更新。
- **均方误差（MSE）**：预测与目标之差的平方再求平均，例如 `(预测−目标)²`；在向量上通常先计算各维平方和或均值。

> 直觉：训练是“调旋钮”，推理是“使用调好的机器”。

### 2.3 潜变量、潜空间和表示

**潜变量（latent variable）** 是用于描述数据但未直接作为原始观测给出的内部变量。**潜空间（latent space）** 是这些变量所在的空间。你可以把它想成一种压缩后的“内部描述”，但不要以为每一个维度一定对应人类能命名的某个概念。

本文中 `z` 有两种用途，务必看上下文：

1. GAN 中，`z` 通常是输入生成器的随机潜向量；
2. 课件的 Rectified Flow 公式中，`z` 是与真实数据 `x` 配对的噪声。

在潜空间扩散中，还会有“图像经编码得到的 latent”。为避免混淆，下文有时记它为 `h`，而将噪声写为 `ε`。它们不一定是同一个东西。

## 3. 课前回顾：自回归与 VAE

### 3.1 自回归：一次预测一个元素

把样本写为 `x=(x₁,x₂,…,x_N)`，概率链式法则给出：

$$
p_\theta(x)=\prod_{i=1}^{N} p_\theta(x_i\mid x_1,\ldots,x_{i-1}).
$$

意思是：先预测第一个元素，再根据前面元素预测第二个，依次类推。文本生成里的“根据前文预测下一个 token（词元）”就是常见例子。生成图像时，元素可以是像素，也可以是压缩后的离散图像 token。

**优点：**训练目标直观，可以计算由各条件概率相乘得到的序列概率。**代价：**通常需要依次生成，序列很长时可能慢；每一步也不是完全不可以借助缓存和并行工程优化。

### 3.2 VAE：先学一个潜空间

VAE（Variational Autoencoder，**变分自编码器**）包含：

- **编码器** `q_φ(z∣x)`：根据数据 `x` 给出潜变量 `z` 的概率分布；`φ` 是编码器参数。
- **先验** `p(z)`：预先选定的潜变量分布，常用标准高斯。
- **解码器** `p_θ(x∣z)`：给定潜变量，描述数据如何产生。

理想情况下希望最大化 `log p_θ(x)`，但对所有可能的潜变量积分往往很难。于是 VAE 最大化一个可计算的**证据下界** ELBO（Evidence Lower Bound）：

$$
\log p_\theta(x)\geq
\underbrace{\mathbb E_{z\sim q_\phi(z\mid x)}[\log p_\theta(x\mid z)]}_{\text{重建项}}
-\underbrace{D_{\mathrm{KL}}\big(q_\phi(z\mid x)\Vert p(z)\big)}_{\text{潜分布正则化}}.
$$

第一项鼓励从编码后的信息重建原样本；第二项用 **KL 散度**衡量编码分布与先验的差异，防止潜空间过于杂乱，使从先验采样更有意义。KL 非负，但通常不对称，不能把它当普通距离。

> **课件第 9 页注意：**左侧写成 `p_θ(x)`，右侧却是对数形式的 ELBO；标准不等式左边应为 **`log p_θ(x)`**。这不是一个可以忽略的记号差异。

## 4. GAN：生成器与判别器的博弈

课件范围：pp. 11–35。原始论文：[Generative Adversarial Nets](https://arxiv.org/abs/1406.2661)。

### 4.1 两个角色

GAN（Generative Adversarial Network，**生成对抗网络**）有两部分：

- **生成器 `G`**：接收随机噪声 `z`，输出假样本 `G(z)`。
- **判别器 `D`**：接收样本，输出它看起来来自真实数据的分数，常写为 `D(x)∈(0,1)`。

```text
真实图片 x ─────────────────────> D ──> 希望输出接近 1
随机噪声 z ──> G ──> 假图片 G(z) ─> D ──> 判别器希望接近 0
                                            生成器希望接近 1
```

类比：生成器像不断练习的仿画者，判别器像鉴定师。鉴定师通过真实/生成样本学习区分；仿画者通过鉴定师的反馈学习改进。这个类比只是辅助理解，GAN 不需要人工鉴定师实时参与。

### 4.2 目标函数到底在说什么？

原始 GAN 的目标是：

$$
\min_G\max_D V(G,D)
=\mathbb E_{x\sim p_{data}}[\log D(x)]
+\mathbb E_{z\sim p(z)}[\log(1-D(G(z)))].
$$

拆开看：

1. 第一项：当真实样本的 `D(x)` 接近 1 时，`log D(x)` 越接近 0。判别器要**最大化**这一项，所以倾向于认为真样本是真的。
2. 第二项：当假样本的 `D(G(z))` 接近 0 时，`log(1−D(G(z)))` 越接近 0。判别器也希望最大化它，所以倾向于识别假样本。
3. 生成器不能改变真实样本项，它通过改变 `G(z)` **最小化**第二项，试图让判别器给假样本更高的真实分数。

`min_G max_D` 叫 **minimax（极小极大）博弈**：两者对同一目标的偏好相反。训练时并不是每次都找到全局最优的判别器和生成器，而是交替更新。

### 4.3 一次训练循环

```text
重复：
  1. 抽真实数据 x 和随机噪声 z。
  2. 暂时固定 G，更新 D：真样本分数提高，假样本分数降低。
  3. 抽新噪声，暂时固定 D，更新 G：让 D 更愿意把 G(z) 判为真。
```

“固定 D”是说不更新 D 的参数；为训练 G，梯度仍需**穿过 D** 回传到 G。实践中更新次数、学习率和其他稳定化方法可调整，不一定严格一比一。

### 4.4 为什么常用非饱和损失？

早期 G 很差，D 轻易判断 `D(G(z))≈0`。直接最小化原始生成器项 `log(1−D(G(z)))` 时，经过判别器的梯度可能很弱，G 学得慢，这叫**梯度饱和**。

常用替代目标：

$$
L_G=-\mathbb E_z[\log D(G(z))].
$$

最小化它也鼓励 `D(G(z))` 增大，但训练初期通常能给出更强梯度。**判别器目标不因此变成同一个目标**；这是生成器一侧常用的替代损失，不是原 minimax 目标的字面同一个函数。

### 4.5 理想判别器告诉我们什么？

假设固定 G，真实分布和生成分布分别为 `p_data`、`p_G`，在理想条件下最优判别器为：

$$
D_G^*(x)=\frac{p_{data}(x)}{p_{data}(x)+p_G(x)}.
$$

分母非零时，它会比较当前位置两种分布的相对密度。若两者完全相同，`D* = 1/2`，判别器无法仅凭样本区分来源。这是理想理论结论；实际训练不保证必然达到。

### 4.6 为什么 GAN 又好用又难训练？

**优点：**生成时通常只需一次运行 G；在很多任务上有很好的视觉效果。

**困难：**

- **不稳定**：G、D 同时变化，不像单纯优化固定目标；其中一方过强或过弱都可能出问题。
- **模式崩塌（mode collapse）**：G 反复生成少数类型的样本，忽略真实分布的其他部分。例如只会生成一种花色的猫。不是所有 GAN 都必然发生。
- **损失难解读**：G 的损失受不断变化的 D 影响，单看一条损失曲线不足以判断生成质量、多样性或训练稳定性；并非完全没有损失曲线可画。
- **模型规模和条件控制**：历史上扩展到大型、复杂条件任务时面临挑战；这是经验总结而非数学上“不可能”。

### 4.7 DCGAN、StyleGAN 与插值

- **DCGAN**：用卷积神经网络（CNN）设计 G 和 D，是深度卷积 GAN 的重要早期架构。卷积擅长处理图像中的局部空间结构。[DCGAN 论文](https://arxiv.org/abs/1511.06434)。
- **StyleGAN**：通过映射网络和逐层风格调制控制图像特征；原始 StyleGAN 使用 AdaIN，同时还引入独立噪声以影响随机细节。后续版本的调制机制有变化，不应把所有 StyleGAN 一概等同于原版 AdaIN。[StyleGAN 论文](https://arxiv.org/abs/1812.04948)。
- **AdaIN（自适应实例归一化）**：简化写作 `AdaIN(a,s,b)=s·(a−μ(a))/σ(a)+b`。先按特征统计量归一化，再用风格相关的缩放 `s` 和偏移 `b` 调整。实际实现会处理数值稳定项和维度广播；具体尺度/偏移由架构产生。
- **潜空间插值**：给两个潜向量 `z₀,z₁`，取 `z(t)=(1−t)z₀+t z₁`，观察 `G(z(t))`。在一些训练良好的模型中，图片会平滑变化，但并不保证每条直线都对应语义合理的过渡。

## 5. 从 GAN 到扩散与流匹配

课件 pp. 36–42 将许多相关方法放在宽泛的“扩散模型”叙述下，重点用 **Rectified Flow（整流流）**讲解。可以先用同一幅图理解它们的共同目标：

```text
简单的噪声分布  ──逐步变换──>  复杂的数据分布
      容易抽样                      有图像结构
```

但要分清：**经典扩散模型**通常从随机加噪与学习反向过程出发；**流匹配 / Rectified Flow**在常见形式中直接学习一个连续时间速度场，再解确定性常微分方程。它们有关联、某些形式可互相联系，但不能把所有具体训练公式混为一谈。

生成图片不是“从某张特定真实图片开始去噪”。生成时通常只提供全新噪声和可选条件，模型学习的是分布层面的变换；训练时使用的数据只是提供监督。

下面先把“图像”压缩成一个数来推导。真实系统只是把同样的运算扩展到向量或张量。

## 6. Rectified Flow：一步步推导

课件 pp. 43–57；进一步阅读：[Rectified Flow 原论文](https://arxiv.org/abs/2209.03003)、[Flow Matching](https://arxiv.org/abs/2210.02747)。

### 6.1 先连接真实数据和噪声

随机选择：

- 真实数据 `x ~ p_data`；
- 噪声 `z ~ p_noise`，如标准高斯；
- 时间 `t ~ Uniform(0,1)`，即在 0 到 1 间均匀取值。

在这个教学版本中，通常独立抽取 `x` 和 `z`，然后做线性插值：

$$
x_t=(1-t)x+t z.
$$

| 时间 | 所处位置 | 解释 |
|---|---|---|
| `t=0` | `x₀=x` | 纯数据 |
| `t=0.5` | `x₀.₅=(x+z)/2` | 数据和噪声各占一半 |
| `t=1` | `x₁=z` | 纯噪声 |

**数字例子：**若 `x=2`、`z=−1`、`t=0.25`，则 `x_t=0.75×2+0.25×(−1)=1.25`。这里 `t` 是插值时间/噪声程度，不是视频的帧时间。

### 6.2 监督信号：速度从哪里来？

把上式对 `t` 求导：

$$
\frac{d x_t}{dt}=z-x=:v_{gt}.
$$

`v_gt` 中的 `gt` 是 **ground truth（训练目标/真值）** 的缩写。对某一个固定的 `(x,z)` 配对，直线路径的速度始终是 `z−x`。上面的例子里，速度为 `−1−2=−3`：随着 `t` 增大，位置每单位时间减少 3。

请牢记：这里速度定义的方向是**从数据走向噪声**。生成要反着走。

### 6.3 网络要学什么？

用神经网络 `v_θ(x_t,t)` 根据当前位置和时间预测速度。训练损失：

$$
L(\theta)=\mathbb E_{x,z,t}\left[\left\|v_\theta(x_t,t)-(z-x)\right\|_2^2\right].
$$

`‖·‖₂²` 是各维误差平方之和或按实现取均值；整体比例不改变理解。训练流程：

```text
取一张真实图片 x
取一份同形状的随机噪声 z
随机取时间 t
计算混合状态 x_t = (1-t)x + tz
计算目标速度 z-x
网络输入 (x_t, t)，输出预测速度
比较预测与目标，用 MSE 更新参数
```

**重要：**网络只看到 `x_t,t`，并不知道原始配对的 `x,z`。同一个位置可能由不同配对产生，所以网络学到的不是“唯一找回原始配对”，而是适合整体分布运输的速度。第 8 节解释这一点。

### 6.4 如何从噪声生成？

训练好以后，从 `x₁ ~ p_noise` 出发，沿时间反向走。取 `T` 个等长步，步长 `Δt=−1/T`：

$$
t_k=1-\frac{k}{T},\qquad
x_{t_{k+1}}\approx x_{t_k}-\frac{1}{T}v_\theta(x_{t_k},t_k),\quad k=0,\ldots,T-1.
$$

这叫**显式欧拉法（Euler method）**：用当前位置的速度近似接下来一小段的变化。这里减号来自 `Δt<0`。正向速度 `z−x` 指向噪声，反向更新 `−v/T` 才朝数据侧。

**沿已知直线的玩具例子：**`x=2,z=−1`，故 `v=−3`。从 `−1` 出发，取 `T=3`，每步减去 `−3/3`，依次得到 `0,1,2`。这个例子用到了已知配对的真实速度，是解释方向的 **oracle（全知）示例**，不是可直接用于真实生成的算法；真实生成时没有目标 `x`，要依赖学到的速度场。

**步数如何影响结果？**更多步通常能减小数值离散误差，但需要更多次网络计算，且总质量还受模型误差、采样器与步长安排影响，不能保证越多越好。课件的约 50 步是示例，不是普适规定。

> **时间列表的边界：**做 `T` 次等步长更新时，用 `t=1,1−1/T,…,1/T` 评估，共 `T` 次，最后到达 0。若把 `t=0` 也作为额外更新点，就多走了一步；课件第 56 页列表可避免按此误读。

### 6.5 直线训练路径 ≠ 每条生成轨迹必然是直线

训练中每个选定配对的连接线是直的，但某个位置可能被多条线经过；网络学的是这些训练目标的条件平均。由于平均速度会随位置、时间变化，最终积分轨迹不一定严格为直线。某些整流 / reflow 技术通过重新配对等方式改善路径，不能把“训练时线性插值”直接等同于“任何生成轨迹一条直线”。

## 7. 条件生成和 CFG

课件 pp. 58–71；原论文：[Classifier-Free Diffusion Guidance](https://arxiv.org/abs/2207.12598)。

### 7.1 如何让模型听懂条件？

无条件模型只拟合总体数据分布；条件模型还输入 `y`，例如类别、文本、参考图：

$$
v_\theta(x_t,t,y).
$$

训练时，真实样本应与条件匹配，比如图片及其对应描述。目标仍是该配对的 `z−x`；模型同时根据 `x_t`、`t`、`y` 预测。生成时固定 `y` 并从噪声开始，便希望输出满足条件的样本。条件可以是文本的向量表示，不一定是直接输入的字符串。

### 7.2 CFG：用两个预测加强条件

**Classifier-Free Guidance（无分类器引导，CFG）** 的做法通常是：训练时以一定概率丢掉条件，用空条件 `∅` 替代；因此一个网络学会有条件和无条件两种预测。生成时在同一个状态计算：

- `v_y = v_θ(x_t,t,y)`：有条件预测；
- `v_∅ = v_θ(x_t,t,∅)`：无条件预测。

课件采用：

$$
v_{cfg}=(1+w)v_y-wv_\varnothing
=v_y+w(v_y-v_\varnothing).
$$

差值 `v_y−v_∅` 可直观视为“条件带来的方向变化”；将它适当放大，可以让生成更强调条件。**本讲定义的 v 指向加噪方向，反向采样使用的是 `−v_cfg`**，不要把图上的箭头与生成方向混为一谈。

有些软件使用另一参数记法：

$$
v_{cfg}=v_\varnothing+s(v_y-v_\varnothing),\qquad s=1+w.
$$

| 参数 | 结果 |
|---|---|
| 本讲 `w=0` / 常见 `s=1` | 普通有条件预测 |
| 本讲 `w=−1` / 常见 `s=0` | 无条件预测 |
| 本讲 `w>0` / 常见 `s>1` | 在条件差值方向上加强 |

**数值例子：**若 `v_y=2`、`v_∅=1`、`w=2`，则 `v_cfg=3×2−2×1=4`；若 `T=10`，反向欧拉更新量是 `−0.4`。数值只是为了说明公式，不代表实际推荐的引导强度。

### 7.3 代价与权衡

CFG 通常每步需要条件和无条件两次网络评估；它们可合并为一个批次执行，但计算量与显存消耗仍可能明显增加。更强引导经常能改善提示词遵循，但过强可能损害多样性、引入过饱和或伪影；并不存在所有模型通用的最佳值。蒸馏模型有时把引导效果内化，具体取决于训练与实现。

“无分类器”是相对于早期需要额外分类器梯度的 classifier guidance 而言，并不是说条件 `y` 不存在。

## 8. 最优预测与时间采样

课件 pp. 72–81。这里是理解训练目标最容易卡住的地方。

### 8.1 为什么同一个位置会有多个答案？

假设 `t=0.5` 且看到 `x_t=0`。以下配对都成立：

- `x=1,z=−1`，目标速度 `z−x=−2`；
- `x=−1,z=1`，目标速度 `z−x=2`。

网络输入一样，却有不同标签，因此无法每次都猜对某一条样本路径。对于平方误差，理想最优预测是给定输入后所有可能目标的**条件期望**：

$$
v^*(u,t)=\mathbb E[z-x\mid x_t=u,t].
$$

有条件模型再把 `y` 加入条件：`E[z−x∣x_t=u,t,y]`。这是分布意义下的结果；训练有限、模型容量有限时不一定达到理论最优。

**为什么是平均？**对于某一固定输入，设目标随机变量为 `V`、预测为 `a`，展开 `E[(a−V)²] = (a−E[V])²+Var(V)`；第二项与 `a` 无关，所以取 `a=E[V]` 最小。向量情形逐维类似。

### 8.2 两个端点：注意减去当前位置

若 `x,z` 独立，且均值存在：

- 在 `t=1`，`u=x₁=z` 已知：`v*(u,1)=u−E[x]`。
- 在 `t=0`，`u=x₀=x` 已知：`v*(u,0)=E[z]−u`。若标准高斯噪声均值为 0，则为 `−u`。
- 若给定 `y` 且 `z` 与 `(x,y)` 独立，`t=1` 端为 `u−E[x∣y]`。

课件 pp. 74–75 把端点说成“数据均值 / 噪声均值”，可以理解为说明**未知另一端**的平均位置；若预测对象是本讲的速度 `z−x`，严格表达必须包含上面的差值，而不是直接把均值当速度。

> 端点形式较简单，不代表端点就是“完美复原一张图”；对连续采样时间，精确端点出现的概率甚至为零。

### 8.3 为什么会改变时间分布？

均匀采样 `t` 意味着训练时各时间区间被抽到的概率与区间长度成正比。但不同噪声水平的信息量、难度、视觉意义可能不同。**时间采样分布 / 噪声日程（noise schedule）**决定更常训练哪些区域。

一种做法是 **logit-normal**：先取正态随机数 `u`，再令 `t=sigmoid(u)=1/(1+e^(−u))`。通过改变正态分布的均值和方差，可以改变对不同 `t` 区间的重视。某些高分辨率设置还会对噪声水平进行偏移。相关选择由模型与目标决定，不是放之四海而皆准的最优日程；见 [Scaling Rectified Flow Transformers](https://proceedings.mlr.press/v235/esser24a.html)。

区分两种日程：**训练时间采样**决定哪些噪声水平更常进入损失；**推理时间网格**决定生成时在哪些时间点评估模型。二者有关但不是同一件事。

## 9. 潜空间扩散 LDM

课件 pp. 83–96；论文：[High-Resolution Image Synthesis with Latent Diffusion Models](https://arxiv.org/abs/2112.10752)。

### 9.1 为什么不直接在像素上生成？

高清图像很大，反复在全部像素上运行生成网络代价高。潜空间扩散模型（Latent Diffusion Model，**LDM**）先把图片压缩成较小的潜表示，在潜空间执行逐步生成，最后解码回图片。

```text
训练自动编码器：  图片 ─> 编码器 E ─> 潜表示 h ─> 解码器 D ─> 重建图
训练生成模型：    图片 ─> E ─> h ─> 加噪/插值 ─> 学习在潜空间生成
推理：            随机潜噪声 ─> 多步生成 ─> 干净潜表示 ─> D ─> 新图片
```

课件展示的是分阶段流程：先训练编码器/解码器，然后在生成模型训练阶段冻结编码器。实践中也有其他训练方案，不是所有架构都完全相同。

### 9.2 维度例子

设原图 `H×W×3 = 256×256×3`，空间下采样倍数 `D=8`、潜通道数 `C=16`：

- 潜表示尺寸 `H/D×W/D×C = 32×32×16`；
- 像素数值个数 `196,608`，潜表示数值个数 `16,384`，约少 12 倍；
- 空间位置从 `65,536` 变为 `1,024`，少 64 倍，但每个位置的通道数从 3 变为 16。

这是**数值个数和空间位置的例子**，不是训练/推理必然快 12 倍的保证；真实成本还取决于网络、精度、注意力结构和实现。潜通道数也因模型而异，`16` 不是通用标准。

### 9.3 自动编码器如何学到“有用的压缩”？

- **重建损失**：让重建图尽量接近原图，可以采用像素级差异。
- **感知损失（perceptual loss）**：比较预训练特征网络中的表征，让重建更关注视觉结构；具体选择因实现而异。
- **KL 正则**：约束潜空间分布，常在 VAE 类方法中使用。课件强调弱 KL 正则，但不是所有压缩器都必须如此。
- **对抗损失**：通过判别器鼓励重建图看起来更真实。这里 GAN 的判别器辅助训练解码器；它不意味着主生成模型本身就是 GAN。

压缩是有损的：过度压缩会丢失细节；压缩不足又节省不了多少计算。**潜空间质量设置了生成质量的重要上限之一**：如果解码器不能表现某些细节，生成网络也很难凭空通过它还原。

## 10. DiT、文生图与视频生成

课件 pp. 97–105。DiT 指 Diffusion Transformer：用 Transformer 作为扩散/去噪模型的主要网络架构。Transformer 善于处理 token 序列，核心机制包括 attention（注意力），让不同位置的信息相互交互。[DiT 原论文](https://arxiv.org/abs/2212.09748)。

### 10.1 把图片变成 token

假设潜表示是 `128×128×16`。将空间上的 `2×2` 小块打包为一个 **patch（图块）**：

```text
128×128 个潜空间位置
     ↓  每 2×2 个位置合成一个 patch
64×64 个图像 token = 4,096 个 token
```

每个 patch 原始含 `2×2×16=64` 个数，通常再通过投影变成模型所需的向量维度。注意 **token 数量**与**每个 token 的特征维度**是两回事。

> 课件第 101 页写 `64×64 = 1024`，这是算术错误；正确为 **4096**。这里仅纠正按课件给定维度计算的结果，不声称所有 FLUX 配置都使用完全相同的尺寸。官方模型卡说明 FLUX.1 [dev] 是 12B 参数的 rectified-flow transformer：[官方模型卡](https://github.com/black-forest-labs/flux/blob/main/model_cards/FLUX.1-dev.md)。

### 10.2 时间、文本怎么注入？

- **时间嵌入（time embedding）**：把标量 `t` 编码成向量，让网络知道当前噪声水平。可用它预测归一化层的缩放、偏移等参数，称为**自适应归一化 / 调制**。这样同一网络面对不同时间时可改变行为。
- **文本编码器（text encoder）**：把提示词变成一串向量，即文本 embeddings（嵌入表示）。T5、CLIP 等是课件提到的例子。
- **交叉注意力（cross-attention）**：例如让图像 token 从文本 token 中读取相关信息。
- **联合注意力（joint attention）**：让不同模态的 token 按某种架构设计一起交互。具体结构随模型而异，不是所有 DiT 都采用同一注入方式。

**文生图推理的概念流程：**

```text
提示词 ──> 文本编码器 ──> 文本向量 ─────────────┐
随机潜噪声 ──> 多次调用生成 Transformer <──────┤
                 ↑ 时间 t，可能还有 CFG          │
               干净潜表示 ──> 图像解码器 ──> 图片
```

注意图中“一次网络预测”输出的可能是速度、噪声或其他参数化；经过采样器的多次更新才得到最终潜表示，不应把每一次网络输出都称为“干净潜表示”。

### 10.3 视频：多出时间维度

视频不仅有高、宽和颜色通道，还包含帧。潜表示可写成 `帧方向×高度×宽度×通道`。视频模型需要同时兼顾：

- 单帧质量；
- 前后帧中的物体、身份和运动的一致性；
- 文本与动作的对应；
- 大量时空 token 带来的计算与内存成本。

课件第 104 页的例子：潜空间给出 `32×128×72×16`，以 `2×2` 空间 patch 计算，token 数为 `32×64×36=73,728`，约 **74K**。但同页输出潜表示又标作 **33×128×72×16**；若按 33 计算则是 `33×64×36=76,032`，约 **76K**。这是课件内部维度不一致，不能悄悄视为同一个精确值。Movie Gen 论文概述给出的最大上下文约 73K 视频 token，与前一个数量级相近，但不能据此推定课件中 32 与 33 的具体原因。[Movie Gen 论文](https://arxiv.org/abs/2410.13720)。

> 自注意力的常规实现，其注意力矩阵大小随 token 数近似按 `N²` 增长；实际系统可以采用局部、稀疏或其他高效策略，因此不能以此推断所有视频模型的具体成本。

## 11. 蒸馏：让生成更快

课件 pp. 106–107。

**知识蒸馏（distillation）**：用一个已有的、较慢或较强的**教师模型**，训练一个希望更高效的**学生模型**，让后者学会近似教师行为。对逐步生成模型，目标可能是让学生用更少步骤达到类似结果。

- 常规模型可能需要几十次网络评估；
- 学生可被训练成少步甚至一步生成；
- 有些方法也尝试将 CFG 效果融入学生，减少推理时重复计算；
- 步数下降、效果、训练成本之间存在权衡，一步不必然更好。

不同蒸馏方法的目标、训练细节不同。“把采样步数直接从 50 改为 1”一般不等于蒸馏；后者需要额外训练。阅读：[Progressive Distillation](https://arxiv.org/abs/2202.00512)、[Consistency Models](https://arxiv.org/abs/2303.01469)。

## 12. 广义扩散与其他数学视角

课件 pp. 108–118。以下是扩展视角，首次阅读可以先掌握粗体结论。

### 12.1 一般化插值与预测目标

把不同方案写成一个统一模板：

$$
x_t=a(t)x+b(t)z,\qquad y_{gt}=c(t)x+d(t)z.
$$

`a,b` 控制数据和噪声如何混合，`c,d` 控制网络要预测什么；用 `f_θ(x_t,t)` 拟合 `y_gt`。这里的 `y_gt` 是“训练目标”，**不是**前面表示文本条件的 `y`。

| 方案 | `a(t), b(t)` | 例子或解释 |
|---|---|---|
| 本讲直线 RF | `1−t, t` | 预测速度 `z−x`，即 `c=−1,d=1` |
| VP，方差保持 | 满足 `a²+b²=1` 的一类日程 | 若 `x,z` 独立且各维方差均为 1，则混合后各维方差仍为 1 |
| VE，方差增长 | `a=1, b=σ(t)` | `x_t=x+σ(t)z`，增大噪声标准差 `σ(t)` |

对 VE，有限的 `σ` 不会让 `x` 在代数上完全消失；“高噪声主导”是近似。以上一维方差说明也不意味着任何真实数据分布在所有情况下都会保持同样的完整协方差结构。

### 12.2 网络可预测什么？

- **x-prediction**：预测干净数据 `x`，`c=1,d=0`。
- **ε-prediction**：预测噪声 `z`（也常写 `ε`），`c=0,d=1`。
- **v-prediction**：某些 VP 约定下，设 `x_t=a x+b z` 且 `a²+b²=1`，常见目标是 `v=a z−b x`。不同论文的时间方向与符号可能不同，必须检查原定义。

在上述 VP 约定中，可以验证：

$$
x=a x_t-bv,\qquad z=b x_t+av.
$$

把 `x_t=a x+b z`、`v=a z−b x` 代入右侧，利用 `a²+b²=1`，就能得到这两个关系。它说明不同预测对象在**特定系数和条件下**可以相互转换；误差加权、训练目标和数值性质仍可能不同。

> **课件第 113 页有自相矛盾：**它写目标 `b z−a x`，又写 `c=b,d=−a`。按照右侧通式 `c x+d z`，前一目标对应的是 `c=−a,d=b`，而给出的系数组合对应 `b x−a z`。上面展示的是另一组清楚定义的常见 VP 约定；不要把它与本讲 RF 的 `v=z−x` 不加说明地等同。

### 12.3 扩散作为潜变量模型

经典离散扩散模型如 DDPM 构造一系列逐步加噪的隐状态 `x₀,x₁,…,x_T`：前向过程已知；反向过程用神经网络近似，逐步把噪声变成数据。它可以看成多层潜变量模型，并从变分下界推导训练目标。常用的噪声 MSE 是简化或重加权后的目标，不应不加条件地称为“与完整 ELBO 逐项完全相同”。[DDPM 原论文](https://proceedings.neurips.cc/paper/2020/file/4c5bcfec8584af0d967f1ab10179ca4b-Paper.pdf)。

### 12.4 Score：概率密度往哪里增加？

给定密度 `p(x)`，**score function（得分函数）**定义为：

$$
s(x)=\nabla_x\log p(x).
$$

`∇ₓ` 表示对 `x` 各个分量求偏导并组成向量。它指向 `log p(x)` 局部上升最快的方向，不是样本的“质量评分”。例如一维标准高斯 `p(x)∝exp(−x²/2)`，其 score 为 `−x`：正数位置往左，负数位置往右，局部朝密度更高的位置。

在 score-based diffusion 中，模型通常学习各噪声水平对应的 **`∇ₓ log p_t(x)`**，而不是只学习干净数据分布的单一 score。不同噪声水平对应不同分布。此处 `p_t` 是噪声化后的数据边缘分布。

### 12.5 SDE 与 ODE：两种描述连续变化的语言

- **ODE，常微分方程**：给定当前状态和时间，速度场决定瞬时变化。理想化的 RF 采样通常解一条确定性 ODE；起始噪声随机，但固定初始状态与求解器后，轨迹可确定。
- **SDE，随机微分方程**：除确定性漂移外，还含随机扰动，常写作 `dX=f(X,t)dt+g(t)dW`，其中 `W` 是布朗运动。其反向采样需要合适的 score 等信息。
- 某些 score 模型还存在相关的 **probability flow ODE**，在合适条件下与相应 SDE 具有相同时间边缘分布，但路径机制不同。不要把 SDE、ODE 和所有扩散算法当成完全相同的东西。[Score-SDE 论文](https://arxiv.org/abs/2011.13456)。

## 13. 离散潜变量与自回归的回归

课件 pp. 119–120；[VQ-VAE 原论文](https://arxiv.org/abs/1711.00937)。

直接逐像素自回归，序列可能非常长。一个替代方法是先把图像压成更短的**离散 token**序列：

1. **编码**：把图片转成连续特征。
2. **量化（quantization）**：对每个特征，从一个有限的**码本（codebook）**中选择最接近的向量，用该向量的整数编号表示。
3. **解码**：把选中的码本向量还原成图片。
4. **训练自回归先验**：把整数编号序列作为训练数据，学习每个编号在之前编号条件下的概率。
5. **生成**：从自回归模型逐个采样编号，经码本与解码器得到图片。

这类方法如 VQ-VAE 将连续图像映射到离散潜空间。需要区分：**码本编号是离散 token**，但码本里的向量本身是连续数值；压缩能缩短序列，但自回归步骤仍可能随 token 数增加而变慢。

## 14. 课件勘误与易错点

| 位置 | 需要注意 | 更严谨的理解 |
|---|---|---|
| p. 9 | VAE 不等式左边少了对数 | `log p_θ(x) ≥ ELBO` |
| pp. 56 左右 | 列表含 `t=0` 时可能多更新一次 | `T` 次等步长更新使用 `t=1` 到 `1/T`，最后抵达 0 |
| pp. 64–66 | 速度方向图示可能与定义混淆 | `v=z−x` 是加噪方向；生成更新用 `−v` |
| pp. 74–75 | “最优速度是均值”过度简略 | 独立假设下为 `u−E[x]` 或 `E[z]−u` |
| p. 101 | `64×64=1024` | 正确是 `4096` 个 token |
| p. 104 | 视频潜表示时间维度一处 32、一处 33 | 对应 73,728 或 76,032 个 token；暂不猜测差异原因 |
| p. 113 | `v` 的文字公式与 `c,d` 不一致 | 按通式逐项对应；先检查论文定义与时间方向 |
| p. 116 | “学习数据分布 score”是简述 | 通常学习不同噪声水平分布 `p_t` 的 score |

此外：**生成时不知道真实目标图片**；`z−x` 是训练配对的监督信号，而不是推理时可直接计算的答案。**CFG 的参数符号与命名因实现不同**；比较数值前先看具体公式。

## 15. 代码小实验、练习与答案

### 15.1 无需第三方库：验证插值与反向欧拉步

下面的 Python 代码可直接运行。它使用已知 `x,z` 算出的固定速度，因此**只是验证一条训练配对上的数学关系，不是训练模型，也不是能生成新数据的真实采样器**。

```python
# Python 3；无需安装第三方库
x = 2.0                 # 玩具示例中的真实数据
z = -1.0                # 配对噪声
T = 3
velocity = z - x        # oracle：这里只为教学，真实生成时不知道 x

print('训练路径上的插值:')
for t in (0.0, 0.25, 0.5, 1.0):
    xt = (1 - t) * x + t * z
    print(f't={t:.2f}, x_t={xt:.2f}')

print('\n从噪声反向走 T 步:')
state = z
for k in range(T):
    t = 1 - k / T       # 1, 2/3, 1/3；不在 0 再多走一次
    state -= velocity / T
    print(f'第 {k+1} 步，起始 t={t:.3f}，state={state:.2f}')
assert abs(state - x) < 1e-9
```

预期反向状态依次为 `0.00, 1.00, 2.00`。自行修改 `x,z,T`，观察方向和步长。真实模型要把 `velocity` 替换成依赖当前 `state,t` 的网络预测，且不再能使用未知的 `x`。

### 15.2 十道自测题

1. `p(y∣x)` 与 `p(x∣y)` 分别可能用于什么任务？
2. GAN 的 G 和 D 分别希望怎样改变 `D(G(z))`？
3. 判别器固定参数时，生成器训练为何仍需梯度穿过判别器？
4. 若 `x=4,z=−2,t=0.25`，求 `x_t` 和本讲速度 `v`。
5. 从 `t=1` 往 `t=0` 采样时，为什么更新要减去速度乘步长大小？
6. 在 `s` 记法中，CFG 的 `s=1`、`s=0` 分别代表什么？
7. 为什么 MSE 下理想网络面对同一输入的多个可能速度会预测条件平均值？
8. `256×256×3` 经空间 8 倍下采样、潜通道为 16 后，潜表示多大？
9. 若潜网格为 `128×128`、patch 为 `2×2`，有多少图像 token？
10. 少步蒸馏与简单减少采样步数有什么区别？

### 15.3 参考答案

1. 前者可判断给定图片的类别；后者可根据类别或文本生成图片。
2. G 希望分数变大；D 希望假样本分数变小，并希望真实样本分数变大。
3. 只有梯度沿 D 的计算过程传回 G，G 才知道怎样改变输出；固定的是 D 的参数而不是切断梯度。
4. `x_t=0.75×4+0.25×(−2)=2.5`；`v=z−x=−6`。
5. 按本讲定义，速度对应 `t` 增大的方向；反向时间步为负。
6. `s=1` 是普通有条件预测；`s=0` 是无条件预测。
7. 对固定输入，平方误差的期望在预测等于目标条件期望时最小；见第 8.1 节。
8. `32×32×16`。
9. `64×64=4096`。
10. 蒸馏会额外训练学生去适应少步生成；仅减少原模型的步数会增大离散误差或影响效果，不能自动得到同样性能。
